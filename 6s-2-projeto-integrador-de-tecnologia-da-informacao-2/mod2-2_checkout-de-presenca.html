📌 Sobre a Atividade do Módulo 2

Neste módulo, você deverá focar na construção de aplicações web, desktop ou mobile dinâmicas, utilizando frameworks modernos e aplicando boas práticas de estruturação e estilização de páginas.

🎯 Objetivo da atividade:

Desenvolver uma aplicação web dinâmica, aplicando os artefatos que foram desenvolvidos em etapas anteriores (Módulo 1). O projeto deve contemplar:

🌆 Meu Projeto: Cidade Virtual - Cabanagem/PA (MERN Stack)

Para esta atividade de extensão do Módulo 2, desenvolvi a aplicação web Cidade Virtual utilizando a stack MERN (MongoDB, Express.js, React, Node.js). A plataforma conecta moradores, comerciantes e autônomos do bairro Cabanagem (Belém/PA), fortalecendo a economia local e a integração comunitária.

🛠️ Tecnologias utilizadas e decisões de implementação

⚛️ React + Vite

Escolhi React com Vite (ao invés de Create React App) pela maior velocidade de desenvolvimento e build mais rápido. Componentes funcionais com hooks (useState, useEffect, useContext) para gerenciamento de estado.

🎨 CSS Modules

Para estilização, utilizei CSS Modules (arquivos .module.css) para evitar conflitos de nomes e manter o estilo próximo ao componente. Cores, tipografia e variáveis definidas no :root. Responsividade com media queries (Mobile First).

🗄️ MongoDB + Mongoose

Banco de dados NoSQL hospedado no MongoDB Atlas (gratuito). Mongoose como ODM para modelagem de dados (schemas de Comercio, Usuario, Evento). Flexibilidade para evoluir o modelo conforme novas demandas.

🔐 Autenticação JWT

Implementei login e registro com JSON Web Tokens. As senhas são hashadas com bcrypt. Rotas protegidas no backend (middleware auth) e no front (rotas privadas com React Router).

📌 Principais funcionalidades implementadas (CRUD):
  • Comércios: Listagem (com busca por categoria e nome), visualização de detalhes, cadastro (apenas para usuários logados), edição e remoção (apenas dono do cadastro).
  • Eventos: Mural com eventos comunitários, criação (líderes e comerciantes), edição e cancelamento.
  • Usuários: Cadastro, login, perfis diferenciados (morador, comerciante, autônomo, líder).
  • Busca dinâmica: Campo de busca em tempo real que filtra comércios sem recarregar a página (React state).

📱 Estilização responsiva aplicada

A interface da Cidade Virtual foi desenvolvida com abordagem Mobile First, garantindo boa experiência em celulares, tablets e desktops.

Pontos de quebra (breakpoints) definidos:
  • Celular (padrão): até 768px – layout em coluna única, menu hambúrguer, cards ocupam 100% da largura
  • Tablet: 769px a 1024px – grid de 2 colunas para os cards, menu horizontal simplificado
  • Desktop: acima de 1024px – grid de 3 colunas, barra lateral visível, espaçamentos maiores
/* Exemplo de media queries aplicadas */
/* Mobile First (padrão) */
.cards-container {
    display: grid;
    grid-template-columns: 1fr;
    gap: 1rem;
}

/* Tablet */
@media (min-width: 768px) {
    .cards-container {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Desktop */
@media (min-width: 1024px) {
    .cards-container {
        grid-template-columns: repeat(3, 1fr);
    }
}
