🎨 O que é estilização de UI (User Interface)?

Estilização de UI é o processo de aplicar regras visuais a uma interface digital para garantir sua estética, usabilidade e coerência. Isso inclui a definição de cores, tipografia, espaçamentos, tamanhos, animações e interações visuais para tornar a interface intuitiva e agradável ao usuário.

❌ Sem estilização

  • Apenas HTML puro (navegador padrão)
  • Fonte Times New Roman, fundo branco, links azuis sublinhados
  • Formulários desalinhados, sem hierarquia visual
  • Experiência: amadora, pouco profissional

✅ Com estilização (UI bem feita)

  • Cores que representam a marca (ex: verde para sustentabilidade)
  • Tipografia legível e hierarquizada (títulos, subtítulos, corpo)
  • Espaçamentos consistentes, botões com hover, cards com sombra
  • Experiência: confiável, agradável, profissional
💡 Por que isso importa para a Cidade Virtual? Um site com boa estilização passa credibilidade para comerciantes e moradores. Cores amigáveis (verde + laranja), fonte legível, cards organizados e botões com feedback visual aumentam a confiança e a taxa de adoção da plataforma.

📘 CSS: A linguagem da estilização

CSS (Cascading Style Sheets) é a linguagem que define a aparência de documentos HTML. Enquanto o HTML estrutura o conteúdo, o CSS controla cores, fontes, posicionamento, tamanhos, animações e responsividade.

Sintaxe básica do CSS: 
seletor {
    propriedade: valor;
}
Exemplo prático: 
/* Estiliza todos os botões do sistema */
button {
    background-color: #0066cc;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 4px;
    cursor: pointer;
}

/* Efeito ao passar o mouse */
button:hover {
    background-color: #245;
}

🎯 Demonstração visual (botão estilizado)

🔍 Seletores CSS: Como "mirar" nos elementos

Seletores são padrões que dizem ao CSS quais elementos HTML estilizar. Dominá-los é essencial para um código limpo e eficiente.

📌 Seletor de elemento

p { color: blue; } → estiliza todos os parágrafos.

📌 Seletor de classe (.classe)

.card { border: 1px solid #ddd; } → estiliza todos os elementos com class="card".

📌 Seletor de ID (#id)

#cabecalho { background: #245; } → estiliza o elemento com id="cabecalho".

📌 Seletor descendente

.menu a { color: white; } → estiliza links dentro de elementos com class="menu".

💡 Boas práticas: Prefira classes ao invés de IDs (maior reutilização). Evite seletores muito específicos (ex: body div section article p). Use nomes semânticos em inglês: .card-comercio, .btn-primario.

📦 Box Model: A base do layout CSS

TODO elemento HTML é uma caixa retangular. O Box Model define como essa caixa é composta:

Conteúdo (texto, imagem, etc.)

↑ padding (espaço interno)

border (borda)

margin (espaço externo)

Propriedades do Box Model:
  • content: área onde fica o texto/imagens (largura x altura)
  • padding: espaço interno entre o conteúdo e a borda
  • border: traço ao redor do padding
  • margin: espaço externo entre a borda e outros elementos
/* Exemplo de aplicação na Cidade Virtual */
.card-comercio {
    width: 300px;
    padding: 15px;      /* Espaço interno */
    margin: 10px;       /* Espaço entre cards */
    border: 1px solid #ddd;
    border-radius: 8px;
}

📐 Layouts responsivos: Flexbox e CSS Grid

Antigamente, layouts eram feitos com tabelas ou floats (muito frágil). Hoje, temos duas ferramentas poderosas: Flexbox (para layouts 1D - linhas ou colunas) e Grid (para layouts 2D - linhas e colunas simultaneamente).

Flexbox (ótimo para menus, barras laterais, cards em linha):

📱 Responsividade: Um site para todas as telas

Responsividade é a capacidade de um site se adaptar a diferentes tamanhos de tela (desktop, tablet, celular). A principal ferramenta CSS para isso são as media queries.

Sintaxe básica: 
/* Layout para celulares (largura máxima 768px) */
@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
    .card {
        width: 100%;
    }
}

/* Layout para tablets (entre 769px e 1024px) */
@media (min-width: 769px) and (max-width: 1024px) {
    .card {
        width: 48%;
    }
}
📱 Mobile First vs Desktop First: A abordagem "mobile first" começa o CSS pelo celular e usa media queries com min-width para telas maiores. É a recomendada atualmente, pois prioriza a experiência em dispositivos móveis (mais de 60% do tráfego web).

🏗️ Estruturação de páginas e arquitetura CSS

À medida que o projeto cresce, o CSS pode virar uma "bagunça". Para evitar isso, usamos metodologias de organização e boas práticas.

📌 Metodologia BEM (Block Element Modifier):

BEM é um padrão de nomenclatura que torna o CSS mais legível e de fácil manutenção.

  • Bloco: Componente independente (ex: .card)
  • Elemento: Parte do bloco (ex: .card__titulo)
  • Modificador: Variação do bloco/elemento (ex: .card--destaque)
/* Exemplo BEM para um card de comércio */
.card { }
.card__titulo { }
.card__endereco { }
.card--destaque { }
📁 Organização de arquivos CSS (para projetos maiores):
  • base.css – reset, variáveis, estilos globais
  • components.css – buttons, cards, forms, modal
  • layout.css – header, footer, grid principal, sidebar
  • pages.css – estilos específicos de cada página (home, perfil, admin)
  • responsive.css – media queries
💡 No React (Cidade Virtual): Preferimos CSS Modules (arquivos .module.css) ou Styled Components (CSS dentro do JS). Isso evita conflitos de nomes e mantém o estilo próximo ao componente. Ou ainda, Tailwind CSS para produtividade com classes utilitárias.

🏙️ Exemplo prático: Estrutura CSS da Cidade Virtual

Paleta de cores (identidade visual):
  • Verde escuro (#1a3c34): cabeçalho, rodapé, botões primários
  • Verde médio (#2a6b5e): hovers, detalhes, links
  • Laranja (#ffa500): destaques, botões de call-to-action, badges
  • Cinza claro (#f5f5f5): fundo de cards, seções secundárias
Tipografia:
  • Títulos: 'Poppins', sans-serif (peso 600)
  • Corpo: 'Inter', sans-serif (peso 400, tamanho 16px)
  • Espaçamento: line-height 1.5 para legibilidade
Layout da página inicial (estrutura em componentes React + CSS): 
/* Home.module.css - Mobile First */
.container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 1rem;
}

.hero {
    background: linear-gradient(135deg, #1a3c34, #2a6b5e);
    color: white;
    padding: 3rem 1rem;
    border-radius: 12px;
    text-align: center;
}

.grid-comercios {
    display: grid;
    grid-template-columns: 1fr;
    gap: 1.5rem;
}

@media (min-width: 768px) {
    .grid-comercios {
        grid-template-columns: repeat(2, 1fr);
    }

@media (min-width: 1024px) {
    .grid-comercios {
        grid-template-columns: repeat(3, 1fr);
    }
}

⚠️ Desafios comuns e boas práticas em CSS

Desafios:
  • Especificidade excessiva: Usar !important com frequência é um anti-padrão. Prefira aumentar a especificidade com seletores mais específicos ou reorganize o CSS.
  • Estilos que "vazam": Sem uma metodologia (BEM) ou CSS Modules, estilos de um componente afetam outros inesperadamente.
  • Dificuldade com responsividade: Testar apenas no desktop, ignorar mobile. Solução: use as ferramentas do DevTools (modo dispositivo) e media queries.
  • Código repetitivo (DRY): Repetir as mesmas cores, espaçamentos, sombras. Solução: use variáveis CSS (--cor-primaria: #0066cc;).
Boas práticas:

🎨 Variáveis CSS

Defina no :root cores, fontes, espaçamentos. Ex: --primary: #0066cc; → use color: var(--primary);.

📱 Mobile First

Escreva CSS primeiro para celular, depois use min-width para telas maiores. Mais performático e alinhado ao uso atual.

🧩 Componentização

No React, cada componente tem seu próprio CSS (CSS Modules). Isso evita conflitos e facilita manutenção.

🛠️ Ferramentas

Use Prettier para formatação, Stylelint para linting, e Chrome DevTools para depuração.
