Este repositório contém os materiais de estudo, atividades e protótipos desenvolvidos durante os módulos de **Projeto Integrador de Tecnologia da Informação II** no curso de **Tecnologia da Informação** na **UFMS Digital**.

---

## **OBJETIVO**

Oportunizar a vivência prática-profissional em desenvolvimento de software, mediante a aplicação dos conhecimentos adquiridos durante o curso em problemas reais identificados, aprofundando conceitos de análise de requisitos, desenvolvimento web, banco de dados, controle de versão e testes de qualidade.

### **Objetivos Específicos**

- Identificar e definir problemas de software, realizando a análise de requisitos e o planejamento de soluções;
- Construir aplicações web dinâmicas utilizando frameworks modernos, HTML e CSS responsivo;
- Modelar e manipular bancos de dados para aplicações web full-stack;
- Utilizar controle de versão (Git) para gerenciamento colaborativo de projetos;
- Implementar testes automatizados e manuais para garantir a qualidade da solução;
- Entregar aplicações funcionais com foco em melhoria contínua e DevOps.

## 📌 **Dica de Estudos**

A disciplina **Projeto Integrador II** é fortemente baseada em práticas modernas de desenvolvimento de software, combinando:

1. **Engenharia de Software** (requisitos, testes, DevOps);
2. **Desenvolvimento Web** (HTML, CSS, frameworks como Vue.js);
3. **Banco de Dados** (modelagem e manipulação de dados);
4. **Ferramentas de versionamento** (Git para controle de versão).

Recomenda-se:

- **Leitura progressiva** dos materiais, acompanhando o cronograma;
- **Prática constante** de codificação, aplicando os conceitos em projetos reais;
- **Uso do Git** desde o início do projeto para versionamento adequado;
- **Testes automatizados** como parte integrante do desenvolvimento.
