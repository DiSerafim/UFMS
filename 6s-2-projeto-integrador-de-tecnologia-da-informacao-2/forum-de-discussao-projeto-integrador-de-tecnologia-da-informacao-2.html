Olá, estudante!

Nesta disciplina, vamos tratar sobre o Projeto Integrador de Tecnologia da Informação II, com foco no desenvolvimento de ações de extensão e na resolução de problemas por meio da análise de requisitos e da construção de aplicações web modernas com frameworks, HTML e CSS, banco de dados, controle de versão e testes. Ao longo dos módulos, você vai avançar do entendimento do problema até uma entrega com mais qualidade, pensando também em ações integradas às temáticas de Educação Ambiental e Direitos Humanos. 💻✅🌍

Pense no tanto de situações do dia a dia que poderiam ser resolvidas com uma aplicação web simples: agendar serviços, registrar solicitações, organizar doações, controlar atendimentos, acompanhar demandas de um projeto social ou dar visibilidade a uma ação ambiental. Quando você transforma uma necessidade em requisitos claros e depois em telas e funcionalidades, a tecnologia deixa de ser ideia e vira solução. 🧩🖥️

Para este fórum, escolha uma demanda real ou plausível do seu contexto e imagine como você estruturaria uma primeira versão web: quais requisitos são indispensáveis, como seria uma página inicial bem organizada com HTML e CSS, quais dados precisariam estar no banco e como você garantiria qualidade com controle de versão e testes básicos. 🔎🗂️🧪

Pergunta norteadora: Qual problema do seu contexto você escolheria para desenvolver uma aplicação web como ação de extensão e como você definiria os requisitos essenciais, os dados do banco e uma estratégia simples de versionamento e testes para entregar com qualidade? 💬

🌆 Cidade Virtual – conectando moradores, comércios locais e serviços comunitários

Tenho um projeto pessoal em desenvolvimento chamado Cidade Virtual onde espero poder ajudar a nossa comunidade de modo geral fazendo a conexão entre os moradores através da tecnologia.

Durante conversas com moradores do meu bairro, identifiquei que pequenos comerciantes e autônomos são praticamente invisíveis digitalmente, dependendo apenas do "boca a boca". Moradores também desconhecem os serviços disponíveis no próprio bairro e não existe um canal centralizado para divulgação de eventos comunitários.

✅ Requisitos Essenciais Identificados

  • Cadastro com perfis diferenciados (morador, comerciante e autônomo)
  • Buscas por categoria e proximidade geográfica
  • Mural de eventos e campanhas (doações, multirões de limpeza, vacinação)
  • Sistema de avaliações para comércios e serviços
  • Interface responsiva (acessível por celular)

🗂️ Modelagem do Banco de Dados

USUARIO (id, nome, email, senha, tipo_perfil [morador/comerciante/autonomo], endereco, telefone, data_cadastro)

COMERCIO (id, nome, categoria, endereco, horario_funcionamento, descricao, avaliacao_media, id_usuario_dono)

SERVICO (id, titulo, descricao, categoria, preco_estimado, id_prestador)

EVENTO (id, titulo, descricao, data_inicio, data_fim, local, tipo_campanha, id_organizador)

AVALIACAO (id, nota, comentario, data, id_avaliador, id_alvo)

🔗 Relacionamentos Principais

• Um USUARIO pode ser dono de um ou mais COMERCIO (1:N)

• Um USUARIO pode oferecer vários SERVICO (1:N)

• Um USUARIO pode criar vários EVENTO (1:N)

• Um USUARIO pode fazer várias AVALIACAO (1:N)

🐙 Estratégia de Versionamento

  • Git + GitHub para controle de versão
  • Branches: main (versão estável) e develop (desenvolvimento ativo)
  • Commits pequenos e descritivos seguindo padrão convencional
  • Pull requests com revisão de código antes do merge

🧪 Estratégia de Testes

  • Testes manuais: Checklist de funcionalidades críticas (cadastro, busca, mural)
  • Testes automatizados: Jest para testar lógica de validação de formulários e regras de negócio
  • Testes de integração: Verificação da comunicação entre front-end e API
  • Qualidade contínua: Commits pequenos e descritivos; revisão de código antes de merge

🌱 Alinhamento com Extensão e Temáticas da Disciplina

O projeto Cidade Virtual se conecta diretamente com:

  • Educação Ambiental: através do mural de campanhas (mutirões de limpeza, coleta seletiva, plantio comunitário)
  • Direitos Humanos: promovendo acesso democrático à informação local e valorizando pequenos comerciantes e autônomos
