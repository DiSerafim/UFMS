Descreva como é possível executar esse programa no computador.

Para executar um programa de alto nível em Python é necessário passar por várias etapas que envolvem a transformação do código fonte em instruções que o processador possa entender.

Executando um Programa em Python.
  1. Código fonte:
    • O código deve ser escrito em um editor de texto e ser salvo com a extensão .py
  2. Interpretação:
    • O interpretador lê o código fonte e o executa, em meu caso tenho instalado em minha máquina: 
      python3 --version / Python 3.11.8
    • O interpretador compila o código fonte em bytecode que é armazenado em arquivos .pyc
  3. Execução:
    • O interpretador executa o bytecode, que o converte em instruções de máquina em tempo de execução.
    • O interpretador também gerencia a memória durante a execução do programa.
