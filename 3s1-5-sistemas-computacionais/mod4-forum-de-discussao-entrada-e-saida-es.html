Materiais

No último módulo da disciplina, estudamos como as operações de entrada e saída (E/S) são realizadas pelo hardware e software do computador.

Conteúdo

Para discutir sobre esses conceitos, estude as leituras e videoaulas selecionadas e, depois, responda às questões a seguir.

1) Vimos que a operação de E/S é realizada através da interação entre o processador e o controlador do dispositivo de E/S e que existem 3 modos diferentes de interação:

  • E/S por polling (ou E/S programada);
  • E/S por interrupção
  • E/S por acesso direto à memória (DMA – Direct Memory Access).

Quais as vantagens da E/S por DMA em relação à E/S apenas por interrupção?

2) Vimos que uma chamada ao sistema operacional (do inglês, system call) é uma solicitação de serviço que um processo do usuário faz ao sistema operacional (SO). Alguns autores denominam a chamada ao sistema operacional de "interrupção de software".

Indique um exemplo de serviço que pode ser solicitado através de uma chamada ao sistema operacional.

Resolução.

1. As vantagens da E/S por DMA em relação à E/S apenas por interrupção.

Eficiência e desempenho:

  • Com o DMA a transferência de dados é realizada diretamente entre o dispositivo de E/S e a memória, liberando a cpu para executar outras tarefas.

Menor sobrecarga do processador:

  • Com a DMA é minimizada a carga de trabalho do processador.

Melhoria no tempo de resposta:

  • O DMA permite transferência de grandes blocos de dados na operação o que resulta em um tempo de resposta mais rápido para E/S.

Redução no número de interrupções:

  • Com o DMA pode transferir grandes blocos de dados em uma única operação, tendo um número muito menor de interrupções geradas comparando com a E/S por interrupção.
2. Exemplo de Serviço Solicitado através de uma Chamada ao Sistema Operacional.

Leitura de um arquivo do sistema de arquivos:

  • Um processo de usuário que realiza uma chamada no sistema, Ex.: read() para que o SO acesse o dispositivo de armazenamento e localize o arquivo desejado, leia os dados do arquivo e os entregue ao processo que fez a chamada.
    • read() fornece como parâmetro um identificador do arquivo, um buffer onde os dados lidos serão armazenados e o número de bytes a serem lidos.
    • O SO ao receber a chamada realiza operações necessárias para acessar o dispositivo de armazenamento, localiza o arquivo, ler os dados e os coloca no buffer fornecido pelo processo de usuário.
    • Após a leitura o SO retorna ao processo de usuário, indicando quantos bytes foram lidos.
