Materiais

Neste módulo, você revisitou os fundamentos da web e a linguagem JS, uma dentre várias outras linguagens de programação que podem ser utilizadas na Web. Vamos discutir sobre a escolha da linguagem de programação em projetos web?

A escolha da linguagem de programação é uma decisão crucial no desenvolvimento web. Ela afeta diretamente o desempenho, a manutenção e a escalabilidade de um projeto. Neste fórum, convido você a explorar as considerações envolvidas nesta escolha.

Resolução.

Projeto: Estudando&Programando

Descrição:

Tenho vontade e farei brevemente um site(e-learning and programming) onde eu irei expor meus meus estudos, projetos desenvolvidos em aulas e portfolio. O objetivo é centralizar minhas aulas e projetos para me ajudar a revisar e, ao mesmo tempo, criar uma plataforma de aprendizado aberta para que outras pessoas possam estudar e aprender com os conteúdos. O site permitirá que usuários acessem as aulas de forma organizada por módulos, tenham acesso a projetos desenvolvidos.

Linguagem escolhida:

Javascript, Node(para o back-end), React(para o front-end).

Justificativa:
  • Organização e atualização:
    • Poderei organizar os conteúdos em módulos e atualizar as aulas e o portfolio de forma fácil.
  • Comunidade ativa e recursos de aprendizado:
    • O Javascript é uma das linguagens mais utilizadas, e tem muitas bibliotecas que facilitam a implementação de funcionalidades.
  • Capacidade de escalabilidade:
    • Com o React e o Node o site se torna rápido, escalável e mais fácil de adicionar funcionalidades.
Critérios de escolha:
  • Eficiência e usabilidade:
    • O React permite criar uma experiência interativa, bom para navegar entre as aulas e o portfolio sem precisar recarregar a página. O Node é eficiente para processar de forma rápida as interações e fornecer experiência em tempo real.
  • Segurança:
    • Com Node é possível integrar autenticação segura e proteger o conteúdo e o portfolio, armazenar dados dos de maneira segura, e limitar pessoas em areas restritas.
  • Flexibilidade em funcionalidades:
    • JavaScript permite expandir o site de maneira fácil, personalizar, integrar com redes sociais.
Impacto na eficiência e segurança:
  • Eficiência:
    • Com React e Node, o site poderá carregar conteúdos e módulos de maneira rápida, sem a necessidade de atualizar a página, deixando o site mais ágil.
  • Segurança:
    • Aplicarei criptografia de dados e autenticação, para proteger o conteúdo de estudos e projetos, garantindo somente usuários autorizados e ou convidados.
