Pergunta 4

O que a sigla XHTML representa?

  • a. HyperText eXecutable Markup Language
  • b. eXtensible HyperText Markup Language
  • c. eXecutable HyperText Multiple Language
  • d. HyperText eXtensible Markup Language
  • e. eXecutable HyperText Machine Language
Resposta: b. ✅

Resolução:

  • XHTML (eXtensible HyperText Markup Language) é uma reformulação do HTML (HyperText Markup Language) que segue a sintaxe e as regras do XML (eXtensible Markup Language).
    • O objetivo do XHTML é tornar o HTML mais rigoroso em relação à sua estrutura e formatação, promovendo maior consistência e interoperabilidade entre diferentes plataformas e dispositivos.
      • O uso do XHTML permite que desenvolvedores aproveitem as características do XML, como a capacidade de definir novos elementos e atributos, além de oferecer uma forma mais robusta de lidar com erros.

Pergunta 5

Qual é a principal vantagem do uso do CSS em páginas web?

  • a. Redução do uso de banda.
  • b. Separação do conteúdo da apresentação, facilitando a manutenção.
  • c. Aumento do tempo de carregamento da página.
  • d. Melhoria na segurança dos dados.
  • e. Capacidade de armazenamento de dados.
Resposta: b. ✅

Resolução:

  • O CSS (Cascading Style Sheets) permite que o conteúdo HTML e a apresentação visual (como cores, fontes, layouts, etc.) sejam gerenciados separadamente. Isso significa que os desenvolvedores podem alterar a aparência do site sem precisar modificar o HTML, o que facilita a manutenção e a atualização do site.
  • Quando o estilo de uma página é definido em um arquivo CSS separado, as alterações de design podem ser feitas em um único lugar, afetando todas as páginas que usam esse arquivo. Isso economiza tempo e esforço na hora de implementar mudanças.

Pergunta 6

O que a sigla DOM representa no contexto de desenvolvimento web?

  • a. Data Organization Method
  • b. Design Oriented Model
  • c. Dynamic Object Management
  • d. Digital Object Mapping
  • e. Document Object Model
Resposta: e. Document Object Model. ✅

Resolução:

  • Document Object Model: O DOM é uma interface de programação que representa documentos HTML e XML. Ele fornece uma estrutura de dados hierárquica que permite que scripts (como JavaScript) acessem e manipulem a estrutura, o estilo e o conteúdo de um documento.
  • Estrutura Hierárquica: No DOM, cada elemento do documento (como tags HTML) é representado como um objeto. Isso permite que os desenvolvedores interajam com a página web de forma dinâmica, permitindo a criação, modificação e exclusão de elementos em tempo real, o que é essencial para a interatividade das páginas web.

Pergunta 7

Qual é o propósito do HTTP na tecnologia web?

  • a. Criar páginas web interativas.
  • b. Permitir a comunicação entre cliente e servidor na web.
  • c. Facilitar a transferência de arquivos.
  • d. Melhorar a velocidade de navegação na web.
  • e. Proteger dados de usuário na internet.
Resposta: b. ✅

Resolução:

  • HTTP (HyperText Transfer Protocol): É um protocolo de comunicação que permite a troca de informações entre um cliente (como um navegador web) e um servidor web. Ele define como as mensagens são formatadas e transmitidas, além de como os servidores e navegadores devem responder a vários comandos.
  • Comunicação Cliente-Servidor: O HTTP funciona por meio de requisições e respostas. O cliente (por exemplo, um navegador) faz uma requisição a um servidor para acessar um recurso (como uma página web), e o servidor responde com os dados solicitados.

Pergunta 8

Um URL é utilizado para identificar um recurso único na internet e consiste em um nome de hospedeiro e um nome de caminho.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ❌

Resolução:

  • URL (Uniform Resource Locator): É um endereço que identifica um recurso único na internet. Um URL típico inclui várias partes, como:
    • Protocolo: Indica o método de acesso ao recurso, como http:// ou https://.
    • Nome de Hospedeiro (Host): Refere-se ao domínio ou endereço IP do servidor que hospeda o recurso, por exemplo, www.exemplo.com.
    • Caminho (Path): Especifica a localização do recurso no servidor, que pode incluir diretórios e o nome do arquivo, como /pasta/arquivo.html.
    • Parâmetros (opcional): Podem ser incluídos após o caminho, precedidos por um ?, para passar informações adicionais, como ?id=123.
    • Fragmento (opcional): Um fragmento pode ser adicionado após um # para apontar para uma seção específica da página.
  • Um URL não se resume apenas ao nome de hospedeiro e ao nome de caminho; ele pode conter outras partes importantes.

Pergunta 9

Qual é a principal diferença entre HTML e XHTML?

  • a. XHTML é uma versão mais antiga do HTML.
  • b. HTML é usado para páginas web dinâmicas, enquanto XHTML para estáticas.
  • c. XHTML é uma linguagem de programação, enquanto HTML é uma linguagem de marcação.
  • d. XHTML é mais focado em estilização, enquanto HTML é para estruturação.
  • e. XHTML é uma reformulação do HTML com regras mais estritas.
Resposta: e. ✅

Resolução:

  • HTML: É a linguagem de marcação padrão usada para criar páginas web. Possui uma sintaxe mais flexível, permitindo que algumas regras de fechamento de tags e de formatação sejam ignoradas. Isso significa que, em HTML, alguns elementos podem ser omitidos ou não seguidos estritamente pelas regras de formatação.
  • XHTML: É uma reformulação do HTML que combina as características do HTML com as regras de sintaxe do XML (eXtensible Markup Language). As principais características do XHTML incluem:
    • Todas as tags devem ser fechadas.
    • Os atributos devem ser colocados entre aspas.
    • A estrutura deve ser bem formada, o que significa que a ordem das tags e a hierarquia devem ser respeitadas.
    • É mais rigoroso em relação à sintaxe, tornando-o mais compatível com tecnologias de processamento de XML.

Pergunta 10

No HTML e XHTML, a tag de fechamento é sempre opcional e pode ser omitida sem afetar a validade do documento.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ✅

Resolução:

  • No HTML, a tag de fechamento é opcional para certas tags, como <li>, <p>, e <div>, que podem ser omitidas em algumas circunstâncias sem afetar a validade do documento. No entanto, em XHTML, todas as tags devem ser devidamente fechadas, e omitir a tag de fechamento resulta em um documento inválido.
