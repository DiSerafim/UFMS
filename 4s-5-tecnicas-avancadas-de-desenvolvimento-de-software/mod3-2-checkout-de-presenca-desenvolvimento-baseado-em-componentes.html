Materiais

Neste módulo, você aprendeu sobre o Desenvolvimento baseado em Componentes. Agora é hora de colocar seu conhecimento em prática!

O objetivo desta atividade é proporcionar o aprimoramento das suas habilidades em Desenvolvimento baseado em Componentes.

Siga as orientações abaixo para realizar a atividade:

Conteúdo

  1. Escolha uma das opções abaixo para desenvolver um App:
    • 🟢 App 1: Calculadora Simples com Componentes Reutilizáveis
    • 🔵 App 2: Conversor de Unidades Modulável
  2. Desenvolva a opção escolhida:
    • 🟢 Se você escolheu o App 1 (Calculadora Simples com Componentes Reutilizáveis):
      • Crie/use pelo menos dois componentes reutilizáveis para operações matemáticas (adição, subtração, multiplicação e divisão), usando, caso queira, a biblioteca SymPy ou math;
      • Documente cada componente;
      • Desenvolva uma interface de linha de comando usando a biblioteca Click para interagir com os componentes.
    • 🔵 Se você escolheu o App 2 (Conversor de Unidades Modulável):
      • Crie/use pelo menos dois componentes reutilizáveis para conversões de unidades, usando, caso queira, a biblioteca Pint;
      • Documente cada componente;
      • Desenvolva uma interface de linha de comando usando a biblioteca Click para interagir com os componentes.
  3. Critério de Componente:
    • Independentemente da opção escolhida, você deverá desenvolvê-la optando pelo desenvolvimento do zero, pela reutilização de componentes ou por ambos (a escolha é sua, mas, assim que finalizar, deve estar claro nos comentários qual opção foi escolhida). Ou seja, você deverá:
      1. Desenvolver os dois componentes do zero, ou
      2. Reutilizar um componente existente (por exemplo, com SymPy, Pint, ou outros) e desenvolver um componente adicional, ou
      3. Reutilizar dois componentes existentes (por exemplo, com SymPy, Pint, ou outros).
  4. Bibliotecas para reuso:
    • 🟢 Para o App 1 (Calculadora Simples com Componentes Reutilizáveis), você pode utilizar as seguintes bibliotecas:
      • 🗂️ SymPy (Biblioteca para Matemática Simbólica em Python).
      • 📄 Documentação Oficial: SymPy Documentation
      • 🗂️ Biblioteca math (Parte da Biblioteca Padrão do Python).
      • 📄 Documentação Oficial: math - Mathematical functions
    • 🔵 Para o App 2 (Conversor de Unidades Modulável), você pode utilizar a seguinte biblioteca:
      • 🗂️ Pint (Biblioteca para Conversões de Unidades em Python).
      • 📄 Documentação Oficial: Pint Documentation
    • 🟢🔵 Para criar interfaces de linha de comando em Python em ambos os Apps:
      • 🗂️ Biblioteca Click.
      • 📄 Documentação Oficial: Click Documentation

      Nota importante: nesta atividade, as bibliotecas indicadas, como SymPy, math, Click e Pint, são sugestões para auxiliar na implementação do App escolhido. No entanto, você tem a flexibilidade de escolher outras bibliotecas ou abordagens, de acordo com a sua preferência e conhecimento.

  5. Organização do código e envio:
    1. Crie um único arquivo Python (com extensão .py) para o seu App;
    2. Marque claramente, com comentários descritivos, as seções do código relacionadas a cada componente e à interface de linha de comando;
    3. Documente cada trecho do código com comentários explicativos, incluindo a descrição das funcionalidades e como eles podem ser reutilizados;
    4. Indique claramente o App escolhido e o Critério de Componente utilizado (veja o Item 3). Se um componente foi reutilizado, você também deve indicar qual foi a biblioteca usada.
    5. Envie o arquivo .py no espaço de tarefa.

Resolução:

App 1: Calculadora Simples com Componentes Reutilizáveis. 
            # Calculadora Simples com Componentes Reutilizáveis

            # importação das bibliotecas
            import click # biblioteca Python que facilita a criação de interfaces de linha de comando (CLI

            # componente para adição
            def add(a, b):
                # função de adição
                return a + b

            # componente para subtração
            def subtract(a, b):
                # função de subtração
                return a - b

            # componente para multiplicação
            def multiply(a, b):
                # função de multiplicação
                return a * b

            # componente para divisão
            def divide(a, b):
                # função de divisão
                if b == 0:
                    return "Erro ao dividir por zero."
                return a / b

            # Interface de linha de comando
            @click.command()
            @click.option('--operation', type=click.Choice(['add', 'subtract', 'multiply', 'divide']), help="Operação (add, subtract, multiply, divide).")
            @click.option('--a', type=float, help="Primeiro número.")
            @click.option('--b', type=float, help="Segundo número.")
            def calculator(operation, a, b):
                # Calculadora simples.
                if operation == 'add':
                    result = add(a, b)
                elif operation == 'subtract':
                    result = subtract(a, b)
                elif operation == 'multiply':
                    result = multiply(a, b)
                elif operation == 'divide':
                    result = divide(a, b)
                else:
                    result = "Cálculo inválido."

                click.echo(f"Resultado: {result}")

            if __name__ == '__main__':
                
                # Exemplos de execução direta
                print("=== Exemplos de Cálculos ===")
                print(f"Adição (10 + 5): {add(10, 5)}")
                print(f"Subtração (10 - 5): {subtract(10, 5)}")
                print(f"Multiplicação (10 * 5): {multiply(10, 5)}")
                print(f"Divisão (10 / 5): {divide(10, 5)}")
                print(f"Divisão (10 / 0): {divide(10, 0)}")
                print("\n")
                
                # Executa a interface CLI se parâmetros forem passados
                calculator()
