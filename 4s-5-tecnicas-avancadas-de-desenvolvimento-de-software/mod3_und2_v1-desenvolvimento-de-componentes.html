Estudo de caso: TaskHub

Introduza o conceito de Desenvolvimento Baseado em Componentes para permitir a reutilização de funcionalidades.

  • Implementação dos Componentes
  • Integração dos Componentes

Desenvolva um sistema web simples para gerenciamento de tarefas:

  • Crie componente que faça a busca e retorne a informação sobre o endereço usando CEP
  • Adicione campos de endereços (localização) como opcional para cada tarefa, sendo preenchido inicialmente pelo CEP
www.ledipo.eti.br/projetos/taskhub
