Neste módulo, você aprendeu sobre os Impactos na Sociedade, compreendendo como a tecnologia influencia aspectos sociais, econômicos e culturais.

Para você exercitar o conteúdo deste módulo, vou te inserir em alguns cenários. Tente emergir no cenário à luz do conhecimento obtido durante este módulo. Durante a construção e refinamento da sua resposta às questões, dê sugestões pragmáticas de resolução que possam ser aplicadas em um cenário real.

Conteúdo

Envie um texto de, no mínimo, 700 caracteres para responder a seguinte questão:

  1. Imagine que você faz parte de uma equipe de avaliação de sistemas em uma empresa que está considerando a implementação de um novo sistema de informações para otimizar seus processos internos. Que critérios você utilizaria para avaliar a eficácia desse sistema? Como você equilibraria os aspectos técnicos, como desempenho e segurança, com as necessidades do negócio e os impactos na sociedade? Quais métodos de análise você aplicaria para tomar decisões informadas?

Resolução

Avaliação de sistemas de uma empresa.
  1. Critérios para avaliar:
    1. Aspectos técnicos:
      • Desempenho: O sistema deve te um tempo de resposta para lidar com as transações dos usuários sem interrupções.
      • Segurança: O sistema deve ter medidas de segurança de criptografia de dados para controle de acesso.
      • Escalabilidade: O sistemas deve poder crescer conforme a empresa cresce.
      • Integração: O sistema deve poder se integrar com outros sistemas.
    2. Necessidade de negócio:
      • Automatização: O sistemas deve se desenvolvido de forma a poder substituir processos manuais.
      • Custo: O sistema deve ser economicamente viável como investimento, manutenção e suporte.
      • Acessibilidade: O sistema deve permitir que todos os funcionários consigam utiliza-lo.
    3. Impactos na sociedade:
      • Sustentabilidade: Verificar se a solução reduz gastos com recursos físicos.
      • Inclusão: Garantir acessibilidade para pessoas com deficiência.
      • Ética: Avaliar como dados sensíveis serão tratados.

  2. Métodos de análise:
    1. Análise SWOT:
      • Identificar forças, oportunidades, ameaças e fraquezas no sistema.
    2. Prototipagem e teste:
      • Criar um protótipo e realizar testes piloto para avaliar o desempenho do sistema.
    3. Consultas com os stakeholders:
      • Envolver os funcionários na discussão para garantir que o sistema atenda as suas necessidades.
    4. Referências:
      • Comparar o sistema com outros disponíveis para garantir uma melhor competitividade.
