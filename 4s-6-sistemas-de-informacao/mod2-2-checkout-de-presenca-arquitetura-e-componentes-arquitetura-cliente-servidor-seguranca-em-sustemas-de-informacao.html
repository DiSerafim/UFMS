Conteúdo

Envie um texto de, no mínimo, 700 caracteres para responder a seguinte questão:

  1. Pense em um cenário em que uma empresa experimentou uma violação de segurança em seu sistema de informação. Como você aplicaria os conceitos de segurança em sistemas de informação para investigar a violação e identificar suas causas? Além disso, como você ajudaria a empresa a melhorar sua arquitetura e medidas de segurança para evitar futuros incidentes?

Resolução

Investigar violação:
  1. Identificar causas:
    • Revisar logs do sistema para identificar atividades incomuns.
    • Utilizar ferramentas de monitoramento, para analisar dados e coletar.
  2. Isolar o sistema afetado:
    • Desconectar o sistema comprometido para evitar a propagação.
    • Preservar evidências para a análise.
  3. Análise:
    • Examinar os dados coletados para identificar a origem da violação.
    • Identificar as vulnerabilidades.
  4. Relatório:
    • Informar as partes interessadas e reguladores.
    • Documentar o evento.
Medidas de segurança:
  1. Atualizar protocolos:
    • Adotar criptografia como a TLS.
    • Implementar autenticação multifator.
  2. Treinamentos:
    • Promover treinamentos de conscientização de segurança.
    • Revisar o gerenciamento de credenciais.
  3. Adotar segurança:
    • Utilizar firewall para detecção de intrusão.
    • Integrar soluções para monitorar dispositivos conectados.
  4. Testes regulares:
    • Realizar testes para identificar vulnerabilidades.
  5. Backup:
    • Configurar backups para evitar perdas.
    • Testar a recuperação de dados para ter garantia.
