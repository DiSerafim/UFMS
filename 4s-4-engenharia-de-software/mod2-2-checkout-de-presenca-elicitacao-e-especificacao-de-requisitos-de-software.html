ENGENHARIA DE SOFTWARE Concluído

Materiais

Neste módulo, você aprendeu a como identificar e documentar os principais requisitos dos usuários.

A engenharia de requisitos pode ser dividida em diversas fases, tais como elicitação, análise e validação de requisitos. Nesta atividade, vamos colocar em prática algumas tarefas importantes, enfatizando a elicitação de requisitos, na qual o profissional busca coletar o máximo de dados possíveis sobre o novo software.

Faça uma entrevista com um familiar ou amigo/a a respeito de um sistema para gerenciamento de despesas domésticas.

Use os conhecimentos adquiridos neste módulo sobre a realização de entrevistas. Busque informações nos livros da disciplina e procure material adicional, se necessário. É fundamental estudar o conteúdo com atenção antes de realizar a entrevista!

Conteúdo

Para realizar esta atividade:
  1. Redija pelo menos 4 perguntas para a entrevista. Lembre-se de que a entrevista é para elicitação de requisitos para um sistema de gerenciamento de despesas domésticas;
  2. Realize a entrevista e anote as respostas obtidas;
  3. Liste 5 requisitos funcionais obtidos a partir da entrevista;
  4. Liste 2 requisitos não funcionais obtidos a partir da entrevista ou identificados por você;
  5. Crie um arquivo PDF contendo todas essas informações e envie-o no espaço de tarefa.

Resolução:

Sistema de gerenciamento de despesas domésticas

Perguntas e para a entrevista/resposta:

  1. Quais tipos de receitas e despesas domésticas você precisa acompanhar?
    • R: Preciso acompanhar meus ganhos com as corridas feitas com moto aplicativo, além dos gastos com gasolina, aluguel da moto, revisão, seguro, parcela da moto, alimentação, compras extras, despesas com a família e despesas fixa.
  2. Gostaria de visualizar gráficos ou relatórios?
    • R: Sim, seria útil ver gráficos que mostrem a evolução dos ganhos e das despesas ao longo do mês, assim consigo ter clareza o quanto ganho e o quanto gasto e poder economizar.
  3. Que tipos de lembretes seriam úteis para ajudar a lembrar dos pagamentos e vencimentos?
    • R: Seria legal receber lembretes para os pagamentos importantes e vencimentos das faturas e as outras despesas recorrentes.
  4. Como você prefere categorizar suas despesas?
    • R: Eu categorizo as despesas em transporte, alimentação, família, extras e constas, Ter a opção para adicionar mais categorias seria interessante.

Requisitos funcionais:

  1. O sistema deve permitir o cadastro e o acompanhamento de receitas e despesas diárias.
  2. O sistema deve gerar gráficos e relatórios mensais dos ganhos e despesas.
  3. O sistema enviar lembretes automáticos sobre o vencimento das faturas.
  4. O sistema deve permitir a criação e novas categorias.
  5. O sistema deve calcular automaticamente o saldo, o lucro e o prejuízo mensal.

Requisitos não funcionais:

  1. O sistema deve ser fácil e simples de usar e responsivo para acesso via celular.
  2. O sistema deve garantir a segurança dos dados financeiros, protegendo as informações do usuário.
