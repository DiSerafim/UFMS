Módulo 2 - 💬 Fórum de Discussão

💬 Turbinando a Mente com o Pensamento Computacional

Existem quatro passos para solucionar problemas computacionais. São eles:

1. Interpretar o problema proposto.
2. Identificar os dados disponíveis para a sua resolução.
3. Definir o objetivo. Para tal, deve-se perguntar a si: “Qual o resultado que se deseja alcançar?”.
4. Definir o conjunto de passos necessários para atingir o objetivo.

Suponha que um problema computacional possua a seguinte descrição:

“Dados dois números inteiros e positivos, verifique se a soma deles é par”.

Observando os quatro passos anteriores, escreva como você interpreta a relação de cada passo com o problema proposto.

1- Verificar se os números são positivos ou negativos, descobrir se o resultado da soma dos números é par, envolve realizar uma operação de soma.
2- Verificar se o número é par ou impar se são dois números inteiros e positivos.
3- Para quê, que vai me servir essa soma, e por que, tem que ser um número par, resultado esperado é uma resposta afirmativa?
4- a) Receber dois números.
b) São inteiro e positivos.
c) Realizar a soma.
d) Verificar se o resultado da soma é par.
e) O resultado é o esperado?
