1. Como você define um Algoritmo?

Uma sequência de instruções, passo a passo sobre como fazer algo ou resolver problemas.

2. Cite um exemplo de algoritmo que você consegue observar no seu dia a dia.

Preparar-se para ir trabalhar:
- acordar as 6h da manhã.

- enquanto a panela está no fogo, ligo a tv coloco no jornal e vou escovar os dentes. - após escovar os dentes a agua já ferveu então preparo o café.

3. Construa um pequeno texto que relacione os seguintes termos: algoritmo, pseudocódigo, instruções, linguagem de programação e programa de computador.

Algoritmo:
- Uma sequência de instruções Pseudocódigo:
- Uma forma de linguagem natural ou programação usada para descrever de forma simples um algoritmo. Instruções:
- São passos descritos no algoritmo. Linguagem de programação:
- São códigos ou instruções feitas no computador para executar algumas tarefas Programa de computador:
- É um conjunto de instruções que foram escritas usando uma linguagem de programação.
