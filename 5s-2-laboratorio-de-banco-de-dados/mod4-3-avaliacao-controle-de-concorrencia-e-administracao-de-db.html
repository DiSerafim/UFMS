Pergunta 1

Uma política de segurança que concede privilégios amplos a todos os usuários é uma prática recomendada, pois facilita a administração dos bancos de dados.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ✅

📌 Explicação:

  • Conceder privilégios amplos a todos os usuários não é uma prática recomendada. Pelo contrário, essa abordagem compromete a segurança do banco de dados. A boa prática é aplicar o princípio do menor privilégio, ou seja, cada usuário deve ter apenas os acessos necessários para realizar suas funções. Isso reduz o risco de acessos indevidos, vazamento de dados ou alterações não autorizadas.

Pergunta 2

Considere as seguintes práticas aplicadas ao princípio do privilégio mínimo em um ambiente de banco de dados:

  • I. O administrador de banco de dados (DBA) possui permissões para modificar a estrutura do banco e realizar backups, mas só tem acesso aos dados confidenciais dos usuários quando isso for indispensável para executar suas responsabilidades.
  • II. Um desenvolvedor é autorizado a acessar e alterar somente as tabelas e visualizações necessárias para desenvolver e testar os sistemas sob sua responsabilidade.
  • III. As permissões são atribuídas apenas aos objetos do banco de dados que são essenciais para cada usuário ou função desempenhar sua tarefa.

Quais das práticas acima estão em conformidade com o princípio do privilégio mínimo?

  • a. I e II, apenas.
  • b. I e III, apenas.
  • c. I, II e III.
  • d. II e III, apenas.
Resposta: c. ✅

📌 Explicação:

  • O princípio do privilégio mínimo recomenda conceder aos usuários apenas as permissões estritamente necessárias para realizarem suas funções, nada além disso.

Pergunta 3

Qual é a função do comando pg_dump no PostgreSQL?

  • a. Monitorar o desempenho do banco de dados.
  • b. Realizar consultas SQL no banco de dados.
  • c. Restaurar um banco de dados a partir de um arquivo de backup.
  • d. Fazer o backup de um banco de dados, exportando sua estrutura e dados para um arquivo.
Resposta: d. ✅

📌 Explicação:

  • O comando pg_dump é uma ferramenta do PostgreSQL usada para:
    • Criar backups lógicos do banco de dados;
    • Exportar estrutura (schemas) e dados para um arquivo .sql, .tar ou .custom;
    • Esse arquivo pode posteriormente ser usado para restaurar o banco com o comando psql ou pg_restore, dependendo do formato.
                pg_dump -U usuario -d nome_do_banco -f backup.sql

Pergunta 4

Associe os comandos de SQL com suas descrições:

                Criar um novo objeto (...).
                Remover permissões de um usuário (...).
                Conceder permissões a um usuário (...).
                Remover um objeto do banco de dados (...).

Opções: DROP, CREATE, GRANT, REVOKE.

Resposta: ✅ 
                Criar um novo objeto CREATE.
                Remover permissões de um usuário REVOKE.
                Conceder permissões a um usuário GRANT.
                Remover um objeto do banco de dados DROP.

📌 Explicação:

  • CREATE → Cria objetos como tabelas, views, bancos, etc.
  • REVOKE → Retira permissões que foram concedidas.
  • GRANT → Concede permissões para usuários.
  • DROP → Apaga objetos do banco, como tabelas ou bancos inteiros.

Pergunta 6

Qual é a principal responsabilidade de um Database Administrator (DBA)?

  • a. Realizar apenas o backup dos dados.
  • b. Criar relatórios para o setor financeiro.
  • c. Gerenciar a equipe de desenvolvimento.
  • d. Administrar e manter os bancos de dados, garantindo segurança e desempenho.
Resposta: d. ✅

📌 Explicação:

  • A principal responsabilidade de um DBA (Database Administrator) é assegurar que o banco de dados funcione corretamente, esteja seguro, com bom desempenho e disponível para os usuários autorizados. Isso inclui:
    • Gerenciar permissões de acesso;
    • Realizar backups e recuperações;
    • Monitorar e otimizar o desempenho;
    • Garantir a integridade e segurança dos dados;
    • Instalar, configurar e atualizar o sistema de gerenciamento de banco de dados (SGBD).

Pergunta 7

O DBA é responsável por assegurar a integridade dos dados, protegendo-os contra acessos não autorizados.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • O DBA (Administrador de Banco de Dados) é sim responsável por assegurar a integridade dos dados, o que inclui:
    • Proteção contra acessos não autorizados, por meio da configuração de permissões de acesso;
    • Implementação de políticas de segurança, como autenticação, criptografia e auditoria;
    • Definição de restrições e regras de integridade para garantir a consistência dos dados.

Pergunta 8

Qual comando é usado para remover permissões previamente concedidas em SQL?

  • a. CREATE
  • b. REVOKE
  • c. ALTER
  • d. GRANT
Resposta: b. ✅

📌 Explicação:

  • REVOKE é o comando SQL utilizado para remover permissões que foram previamente concedidas a usuários ou funções no banco de dados.
                REVOKE SELECT ON clientes FROM 'joão';

Pergunta 9

A segurança em banco de dados consiste em aplicar políticas que protegem os dados apenas contra acessos externos.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ✅

📌 Explicação:

  • A segurança em banco de dados não protege apenas contra acessos externos, mas também contra:
    • Acessos internos não autorizados (por exemplo, funcionários com permissões inadequadas);
    • Modificações acidentais ou maliciosas;
    • Vazamento de dados sensíveis;
    • Ataques cibernéticos (como SQL Injection);
    • Perda de dados por falhas ou desastres.

Pergunta 10

Por que é importante que o DBA realize backups periódicos?

  • a. Para reduzir os custos de armazenamento.
  • b. Para melhorar o desempenho do banco de dados.
  • c. Para aumentar a velocidade de consulta.
  • d. Para proteger os dados contra perda em caso de falhas.
Resposta: d. ✅

📌 Explicação:

  • Realizar backups periódicos é uma das funções mais críticas de um DBA (Administrador de Banco de Dados), pois garante que, em caso de:
    • Falhas no sistema
    • Erros humanos
    • Ataques cibernéticos (como ransomware)
    • Desastres naturais ou apagões

...os dados possam ser recuperados de forma rápida e segura. Isso minimiza os prejuízos e garante a continuidade das operações da organização.

🔁 Backups permitem restaurar o banco à última versão salva com integridade, evitando perda total ou parcial das informações.
