Neste módulo, você aprendeu sobre controle de concorrência e administração de banco de dados.

Aprendeu que o DBA (administrador de banco de dados) é aquele que desenvolve, realiza as manutenções e monitora o banco de dados de uma organização. Além disso, esse profissional conduz a instalação, os reparos e analisa a estrutura do sistema.

1 - Qual a importância de um DBA para uma empresa?

  • O DBA é importante em uma empresa que dependa de dados para operar, ele é responsável pela garantia de que o banco de dados funcione corretamente, de forma segura, eficiente e com disponibilidade. O DBA realiza tarefas como instalação, configuração, manutenção e otimização do desempenho e controle de acesso aos dados. Ele também é responsável por assegurar que os dados que os dados estejam protegidos contra falhas de segurança.

2 - Descreva com suas palavras a importância do DBA fazer Backup em um banco de dados?

  • O backup nada mais é do que uma cópia do Banco de dados, então ter uma cópia recente é essencial para ter um respaldo de que se algo der errado você tem uma cópia para recuperação. É uma medida de segurança indispensável para manter a integridade e a confiabilidade das informações e dados de uma empresa.
