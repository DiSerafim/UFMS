Materiais

O primeiro passo para aprender SQL é entender que essa se trata de uma linguagem declarativa, com a qual nos preocupamos menos em como as coisas são feitas e nosso trabalho passa a ser informar o que queremos fazer combinando um conjunto de comandos disponibilizado por ela. Os comandos da linguagem SQL são divididos em conjuntos e essa separação é feita de acordo com o que cada comando faz. Comandos que fazem atividades similares são agrupados no mesmo conjunto.

Com base na citação anterior, descreva o significado das siglas e a diferença com exemplos entre as linguagens DML e DDL.

DML - Data Manipulation Language:

  • Comandos para manipular dados:
    • INSERT, UPDATE, DELETE e SELECT.
    • Ex.:
      • INSERT INTO clientes (nome) VALUES ('João')

DDL - Data Definition Language:

  • Comandos para definir estruturas:
    • CRETE, ALTER e DROP.
    • Ex.:
      • CREATE TABLE clientes (id INT PRIMARY KEY)

Diferença:

  • DML opera dados existentes, e DDL define a estrutura do banco de dados.
  • DML é transacional, pode ser desfeito com ROLLBACK, DDL é auto-commit, execução imediata (não reversível).
