Pergunta 1

De acordo com a tabela Curso a seguir, qual é o comando SQL que lista o nome_curso e preco_curso de todos os cursos cadastrados.

                    CREATE TABLE CURSO
                    (cod_curso SERIAL PRIMARY KEY,
                    nome_curso VARCHAR(100) NOT NULL,
                    preco_curso NUMERIC(12,2) NOT NULL,
                    pre_requisito INTEGER);
  • a. SELECT nome_curso, preco_curso FROM CURSO;
  • b. UPDATE nome_curso, preco_curso FROM CURSO;
  • c. SELECT nome_curso, preco_curso WHERE CURSO;
  • d. SELECT nome_curso, preco_curso OF CURSO;
Resposta: a. ✅

📌 Explicação:

  • O comando SELECT é usado para consultar dados no SQL.
  • Devemos especificar as colunas desejadas (nome_curso, preco_curso) após o SELECT.
  • A cláusula FROM indica a tabela de origem dos dados (CURSO).

Pergunta 2

Qual comando SQL pode ser usado para alterar o nome de uma coluna em uma tabela?

  • a. RENAME COLUMN
  • b. ALTER COLUMN
  • c. MODIFY COLUMN
  • d. ALTER TABLE
Resposta: d. ✅

📌 Explicação:

  • ALTER TABLE em conjunto com RENAME COLUMN.

Pergunta 3

Qual comando SQL é utilizado para apagar completamente uma tabela e todos os seus registros do banco de dados?

  • a. REMOVE
  • b. DROP TABLE
  • c. DELETE
  • d. TRUNCATE
Resposta: b. ✅

📌 Explicação:

  • DROP TABLE é usado para apagar completamente uma tabela do banco de dados, incluindo:
    • Todos os registros (dados);
    • A estrutura da tabela (colunas, chaves, índices);
    • Suas dependências (como chaves estrangeiras em outras tabelas).

Pergunta 4

Qual comando SQL é usado para selecionar dados de uma tabela?

  • a. QUERY
  • b. FETCH
  • c. SELECT
  • d. GET
Resposta: c. ✅

📌 Explicação:

  • SELECT é o principal comando SQL para consultar e selecionar dados de uma tabela ou várias tabelas em um banco de dados relacional. Ele permite:
    • Recuperar registros específicos;
    • Filtrar dados com condições (WHERE);
    • Ordenar resultados (ORDER BY);
    • Agrupar informações (GROUP BY);
    • Juntar tabelas (JOIN).

Pergunta 6

Qual comando SQL é utilizado para adicionar uma nova coluna a uma tabela existente?

  • a. INSERT COLUMN
  • b. ADD COLUMN
  • c. MODIFY TABLE
  • d. ALTER TABLE ADD
Resposta: d. ✅

📌 Explicação:

  • ALTER TABLE combinado com ADD é usado para adicionar uma nova coluna a uma tabela existente em SQL.

Pergunta 7

O comando SELECT DISTINCT em uma consulta SQL serve para remover valores duplicados dos resultados.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • SELECT DISTINCT é usado em SQL para retornar apenas valores únicos em um conjunto de resultados, eliminando duplicatas.

Pergunta 8

Qual comando SQL é utilizado para combinar dados de duas tabelas com base em uma coluna comum?

  • a. JOIN
  • b. UNION
  • c. LINK
  • d. MERGE
Resposta: a. ✅

📌 Explicação:

  • JOIN em SQL é utilizado para combinar dados de duas ou mais tabelas com base em uma coluna comum (geralmente uma chave primária ou estrangeira). Ele permite criar relacionamentos entre tabelas diferentes em uma única consulta.

Pergunta 9

Qual comando SQL é utilizado para deletar um registro específico em uma tabela?

  • a. DROP
  • b. DELETE
  • c. REMOVE
  • d. CLEAR
Resposta: d. ✅

📌 Explicação:

  • DELETE é utilizado em SQL para remover um ou mais registros específicos de uma tabela, mantendo a estrutura da tabela intacta.

Pergunta 10

Qual comando SQL é usado para remover uma constraint de uma tabela?

  • a. DELETE CONSTRAINT
  • b. REMOVE CONSTRAINT
  • c. ALTER CONSTRAINT
  • d. DROP CONSTRAINT
Resposta: d. ✅

📌 Explicação:

  • ALTER TABLE combinado com DROP CONSTRAINT é usado para remover uma constraint (restrição) de uma tabela existente em SQL.
