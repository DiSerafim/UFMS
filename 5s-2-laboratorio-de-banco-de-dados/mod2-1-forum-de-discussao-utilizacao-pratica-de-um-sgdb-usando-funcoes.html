Materiais

Neste módulo, você aprendeu sobre funções, procedimentos armazenados e gatilhos.

Aprendemos que ao trabalharmos com o SGBD PostgreSQL não temos necessariamente a função Stored Procedure (SP) definida, como podemos encontrar em diversos outros tipos de SGBD’s. Esasas , na realidade, pequenos trechos de código armazenados do lado do servidor de uma base de dados. Ao contrário do que acontece em outras bases de dados, as SPs no Postgres são definidas como FUNCTIONS, assim como as triggers, tornando esse recurso um pouco mais complicado, dependendo inclusive do seu tipo de retorno.

1 - Na sua percepção, para que tarefa você pode usar uma Função de banco de dados?

  • Para encapsulamento de lógica que são frequentemente utilizados.
  • Para a segurança permitindo o controle de permissões.
  • Para a performance reduzindo a quantidade de dados trafegados entre aplicações.

Ex. calcular o valor total de um pedido:

            CREATE OR REPLACE FUNCTION calcular_total_pedido(pedido_id integer)
            RETURNs numeric AS $$
            DECLARE
                total numeric;
            BEGIN
                SELECT SUM(quantidade * preco_unitario) * (1 - COALESCE(desconto, 0))
                INTO total
                FROM itens_pedido
                JOIN produtos ON itens_pedido.produto_id = produtos.id
                WHERE itens_pedido.pedido_id = calcular_total_pedido.pedido_id;

                RETURN total;
            END;
            $$ LANGUAGE plpgsql;

2 - Descreva algum exemplo onde podemos usar Trigger?

  • Na manutenção de integridade, quando as constraints padrão não são suficientes.
  • Em auditoria para registrar automaticamente alterações em tabelas.
  • Na manutenção de dados, para atualizar de forma automática campos calculados e resumos.

Ex. trigger para registrar histórico de alterações de preços:

            CREATE OR REPLACE FUNCTION registrar_historico_preco()
            RETURNs TRIGGER AS $$
            BEGIN
                IF NEW.preco <> OLD.preco THEN
                    INSERT INTO historico_precos(produto_id, preco_antigo, preco_novo, data_alteracao, usuario)
                    VALUES (OLD.id, OLD.preco, NEW.preco, NOW(), current_user);
                END IF;
                RETURN NEW;
            END;
            $$ LANGUAGE plpgsql;
            
            CREATE TRIGGER tr_historico_preco
            BEFORE UPDATE ON produtos
            FOR EACH ROW
            EXECUTE FUNCTION registrar_historico_preco();
