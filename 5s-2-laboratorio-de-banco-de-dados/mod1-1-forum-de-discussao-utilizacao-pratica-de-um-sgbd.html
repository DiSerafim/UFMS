Materiais

Aprendemos que a linguagem de consulta estruturada (SQL) é uma linguagem de programação para armazenar e processar informações em um banco de dados relacional.

Um banco de dados relacional armazena informações em formato tabular, com linhas e colunas representando diferentes atributos de dados e as várias relações entre os valores destes dados. Você pode usar instruções SQL para armazenar, atualizar, remover, pesquisar e recuperar informações do banco de dados. Também pode usar SQL para manter e otimizar a performance do banco de dados.

Questões:

  2. Qual a importância de se criar uma chave primária em uma tabela?

...

1 - Na sua percepção, qual é a importância de conhecer os comandos da linguagem SQL nos bancos de dados?

  • É fundamental para o trabalho com banco de dados relacionais.
    • Permite criar com INSERT, ler com SELECT, atualizar com UPDATE e deletar com DELETE.
    • Permite criar e deletar tabelas com CREATE/ALTER TABLE e definir o relacionamento entre tabelas.
    • Permite configurações de permissões com GRANT/REVOKE, para proteção de dados sensíveis.
    • Permite criação de índices para ter uma consulta mais rápida.

2 - Qual a importância de se criar uma chave primária em uma tabela?

  • É importante, pois é uma identificação única.
    • Garantia de que cada registro tenha um identificador exclusivo.
    • Evita duplicação de dados.
    • Permite que se estabeleça relacionamentos entre tabelas através de chave estrangeira FOREIGN KEY.
    • Cria automaticamente um índice clusterizado.
    • Acelera operações de busca e junção com JOIN.
