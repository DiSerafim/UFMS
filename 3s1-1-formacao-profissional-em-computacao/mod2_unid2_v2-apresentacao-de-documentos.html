Sistemas de Informação - Aula 20 - Outras atividades de engenharia de software.

Objetivo:

  • Apresentar uma visão geral de outras atividades relacionadas à engenharia de software:
    • Documentação de software
    • Configuração de software
    • Gestão de projeto
    • Garantia de qualidade
    • Manutenção de software

Documentação de software

Produzir a documentação que acompanhará o software quando ele for implantado, vendido ou entregue ao cliente.

  • Normalmente, chamada de "documentação do usuário" ou "manuais do usuário".
  • Podem ser on-line/off-line

Exemplos de documentação de software:

  • Manual de instalação/configuração.
  • Manual do usuário.

Configuração de software

Configuração de software:

  • Conjunto de artefatos (em uma de suas versões) para formar uma versão oficial do software.
  • Inclui artefatos de requisitos, projeto, código implementado, casos de teste executados, manuais, etc.

Gestão de configuração de software:

  • Tarefa de apoio ao desenvolvimento de software.
  • Controlar diferentes versões de artefatos sendo desenvolvidos.
  • Controlar mudanças nas versões dos artefatos.
  • Auditar as diferentes configurações de software.

Gestão de projeto.

Cada software ou sistema a ser desenvolvido é tratado como um projeto diferente.

  • Cada projeto segue os mesmos passos, as mesmas atividades, o mesmo "processo".
  • Cada projeto deve ser gerenciado por um gerente de projeto.

Gestão (gerência/gerenciamento) de projeto

  • Conjunto de atividades para gerenciar um projeto de desenvolvimento de software/sistema.

Garantia de qualidade

Qualidade de software:

  • Grau em que um conjunto de características inerentes ao software/sistema cumpre os requisitos inicialmente estipulado para ele.
  • Conformidade aos requisitos.

Garantia da qualidade de software:

  • Garantir a qualidade do software via definição e normatização de processos de desenvolvimento.
  • Visam a qualidade do produto final, que satisfaça às expectativas do cliente, dentro do que foi acordado inicialmente.

A qualidade do produto está diretamente relacionada à qualidade do processo de desenvolvimento.

  • É comum que a busca por um software de maior qualidade passe necessariamente por uma melhoria no processo de desenvolvimento.

Manutenção de software

Processo de trabalhar sobre um software já desenvolvido ("versão de produção") para:

  • Melhoria e otimização (inclusão de novas funcionalidades desejadas ou necessárias).
  • Reparo de defeitos/deficiências (encontrados durante o uso pelo usuário).
