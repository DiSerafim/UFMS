Análise e projeto.

Objetivo:

  • Apresentar os principais conceitos relacionados as primeiras atividades do processo de engenharia de software :
    • Especificação e análise de requisitos de software.
    • Projeto de software (designer de software).

Requisitos.

  • Objetivos / restrições estabelecidos por clientes/usuários que definem as características do software/sistema.
  • Base para etapas de Projeto (Design) e Desenvolvimento (Implementação)
    • Objetivos: o que o software /sistema deve ter.
    • Restrições: como o software deve/não deve fazer algo.
  • Tipos de requisitos:
    • Requisitos funcionais: relacionados às funções/operações desejadas do software/sistema.
    • Requisitos não funcionais: qualidades globais do software, como: usabilidade, desempenho, portabilidade, etc.

Exemplos de requisitos:

  • Funcionais:
    • "O software deve possibilitar que descontos sejam aplicado para a venda de produtos".
    • "O software deve emitir relatórios sobre vendas realizadas de forma periódica".
    • "O software deve possibilitar o trancamento em disciplinas em que os usuários (alunos) estão matriculados até um determinado período de ocorrência da disciplina".
  • Não Funcionais:
    • "O acesso ao software deve ser realizado apenas por usuários autorizados".
    • "As funções de um determinado módulo do software devem responder no máximo em 30 segundos".
    • "O software deve ser operacionalizado pelo menos nos SO Linux e Windows".

Análise de requisitos.

  • Produção de um documento de requisitos e sua manutenção ao longo do tempo.
  • Atividades principais:
    • Estudos de viabilidade.
    • Identificação.
    • Análise/negociação.
    • Especificação/documentação.
    • Validação.
    • Gestão de alterações.

Projeto de software.

  • Projeto (design) de software.
  • Projeto (desenhar) como o software deve ser implementado:
    • Transformar os requisitos em um conjunto de artefatos capaz de ser interpretado diretamente pelos programadores.
    • Mapear as funcionalidades identificadas durante a análise de requisitos para a arquitetura do software de forma a tornar possível a implementação do software.
  • Diferentes tipos de projeto:
    • Projeto de arquitetura.
    • Projeto de banco de dados.
    • Projeto de interface gráfica.
    • Projeto de componentes.
