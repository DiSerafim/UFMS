Vantagens:
  1. Facilidade de uso: O Bootstrap fornece um conjunto abrangente de estilos pré-definidos e componentes que podem ser facilmente utilizados para criar interfaces de usuário responsivas e atraentes.
  2. Comunidade e suporte: É uma das estruturas mais populares e bem documentadas, com uma grande comunidade de usuários e muitos recursos disponíveis online.
  3. Responsividade: O Bootstrap é altamente responsivo, o que significa que os sites e aplicativos desenvolvidos com ele serão compatíveis com vários dispositivos e tamanhos de tela.
Desvantagens:
  1. Padronização: O uso excessivo do Bootstrap pode resultar em sites e aplicativos com aparência muito padronizada, tornando-os menos distintos.
  2. Peso: Como o Bootstrap inclui muitos recursos e estilos, os arquivos podem ser pesados, o que pode aumentar o tempo de carregamento da página.
  3. Personalização limitada: A personalização de componentes pode ser limitada, o que pode ser um problema se você estiver procurando por uma aparência altamente personalizada.

Vantagens:
  1. Arquitetura robusta: Angular oferece uma estrutura robusta e bem definida para o desenvolvimento de aplicativos da web, o que facilita a manutenção e escalabilidade do código.
  2. Biblioteca oficial: Desenvolvido e mantido pelo Google, Angular possui uma biblioteca oficial e uma documentação abrangente que facilita o aprendizado e o desenvolvimento.
  3. Two-way data binding: Angular oferece vinculação de dados bidirecional, o que significa que qualquer alteração nos dados reflete automaticamente na interface do usuário e vice-versa.
Desvantagens:
  1. Curva de aprendizado: Angular pode ter uma curva de aprendizado íngreme, especialmente para iniciantes, devido à sua complexidade e à necessidade de entender conceitos como módulos, serviços e injeção de dependência.
  2. Rendimento: Aplicações Angular podem ser menos eficientes em termos de desempenho em comparação com estruturas mais leves devido à sua complexidade e ao processo de compilação.
  3. Migração de versão: A migração entre versões principais do Angular pode ser desafiadora, pois as mudanças na estrutura podem exigir uma reescrita substancial do código existente.

Vantagens:
  1. Componentização: React é altamente modular, o que significa que os aplicativos são construídos como uma coleção de componentes reutilizáveis, facilitando a manutenção e a escalabilidade.
  2. Virtual DOM: React utiliza um Virtual DOM eficiente para atualizações de interface do usuário, o que resulta em melhor desempenho e uma experiência de usuário mais fluida.
  3. Flexibilidade: React é altamente flexível e pode ser facilmente integrado com outras bibliotecas e frameworks, permitindo escolher a melhor ferramenta para cada necessidade.
Desvantagens:
  1. Curva de aprendizado: Assim como o Angular, React pode ter uma curva de aprendizado íngreme para iniciantes devido à sua abordagem baseada em componentes e ao uso de JSX.
  2. Ecossistema em mudança: O ecossistema React está em constante evolução, o que pode tornar difícil acompanhar as melhores práticas e as ferramentas mais recentes.
  3. Necessidade de ferramentas adicionais: Para construir um aplicativo React completo, muitas vezes são necessárias várias outras bibliotecas e ferramentas, o que pode adicionar complexidade ao projeto.

Vantagens:
  1. Facilidade de aprendizado: Vue.js é conhecido por sua curva de aprendizado suave, tornando-o uma ótima escolha para iniciantes e para projetos de pequeno a médio porte.
  2. Reatividade: Vue.js oferece reatividade fora da caixa, o que significa que as alterações no estado do aplicativo são automaticamente refletidas na interface do usuário sem a necessidade de manipulação manual do DOM.
  3. Flexibilidade: Vue.js é altamente flexível e pode ser facilmente integrado a projetos existentes, permitindo que você adote gradualmente em partes específicas do seu aplicativo.
Desvantagens:
  1. Menos maduro: Em comparação com outras estruturas como React e Angular, Vue.js pode ser considerado menos maduro em termos de adoção empresarial e recursos disponíveis.
  2. Eco-sistema menor: Embora Vue.js tenha um ecossistema crescente, pode ser um pouco menor em comparação com frameworks mais estabelecidos como React e Angular, o que pode limitar a disponibilidade de plugins e ferramentas de terceiros.
  3. Suporte corporativo: Enquanto o Vue.js é apoiado por uma comunidade ativa, pode não ter o mesmo nível de suporte corporativo oferecido por estruturas como Angular (Google) e React (Facebook).

Vantagens:
  1. Facilidade de uso: jQuery simplifica a manipulação do DOM e a interação com o JavaScript, tornando-o mais fácil de aprender e usar para iniciantes.
  2. Compatibilidade: jQuery é altamente compatível com uma ampla variedade de navegadores, garantindo que seu código funcione consistentemente em diferentes plataformas.
  3. Ampla adoção: jQuery é uma das bibliotecas JavaScript mais populares e amplamente adotadas, com uma grande base de usuários e uma vasta quantidade de plugins disponíveis.
Desvantagens:
  1. Desempenho: Em comparação com as abordagens mais modernas, o jQuery pode ser menos eficiente em termos de desempenho devido ao seu uso pesado do DOM e ao processamento síncrono.
  2. Declínio da relevância: Com o aumento da popularidade de estruturas mais modernas como React e Angular, o uso direto do jQuery está diminuindo, e pode ser considerado menos relevante para o desenvolvimento de aplicativos da web modernos.
  3. Manutenção: O código jQuery pode se tornar rapidamente difícil de manter e escalar à medida que a complexidade do projeto aumenta, devido à sua natureza de manipulação direta do DOM.

Vantagens:
  1. Compatibilidade: Babel permite que você escreva código em JavaScript moderno (ES6/ES7) e compile-o para uma versão mais antiga do JavaScript que seja suportada por navegadores mais antigos.
  2. Ecossistema: Babel é uma peça fundamental no ecossistema moderno de desenvolvimento web, sendo amplamente adotado e integrado com outras ferramentas populares como webpack e ESLint.
  3. Flexibilidade: Com plugins e presets, Babel oferece flexibilidade para personalizar o processo de transpilação de acordo com as necessidades do projeto.
Desvantagens:
  1. Complexidade: Configurar Babel corretamente pode ser um pouco complexo, especialmente para iniciantes, devido à necessidade de entender diferentes plugins e presets.
  2. Overhead: Adicionar Babel ao processo de compilação pode adicionar algum overhead ao tempo de construção do projeto, especialmente em projetos grandes com muitos arquivos JavaScript.

Vantagens:
  1. Plataforma server-side: Node.js permite que você construa aplicações server-side usando JavaScript, o que oferece uma experiência de desenvolvimento mais consistente ao trabalhar com front-end e back-end.
  2. Performance: Node.js é conhecido por sua alta performance e eficiência, graças ao seu modelo de E/S não bloqueante e ao uso do motor V8 do Google.
  3. NPM: Node.js vem com o gerenciador de pacotes npm integrado, que é uma das maiores coleções de bibliotecas de código aberto, facilitando a instalação e gerenciamento de dependências.
Desvantagens:
  1. Escalabilidade vertical: Node.js é mais adequado para escalabilidade vertical, o que significa que é melhor para aplicações que precisam lidar com um grande número de conexões simultâneas, em vez de aplicações que precisam escalar horizontalmente em vários servidores.
  2. Single-threaded: Node.js é single-threaded, o que pode ser um desafio ao lidar com operações de CPU intensivas ou tarefas que bloqueiam a thread por longos períodos de tempo.

Áreas de atuação

Dev front-end

Fica responsável pela criação da parte gráfica de um site e de um produto digital, faz a conversão dos dados em uma interface agradável, usando linguagens como JavaScript, CSS e HTML.

Dev back-end

É responsável pelas funcionalidades do site, pela interação do produto digital com o/a usuário/a, como criação de contas, login, senha, entre outras ações executadas pelos/as clientes. Entre as linguagens necessárias para o desempenho das funções estão: PHP, Ruby, Phyton e Java.

Dev de aplicativo

É quem está preparado/a para programar aplicativos Android e iOS. Esses/as profissionais costumam dominar linguagens de programação como Objective-C., Swift e Java.

Dev Full Stack

É um/a desenvolvedor/a web que sabe trabalhar com aplicativo e site, com front-end e back-end. Por isso, é mais generalista e conhece bem o processo de desenvolver o software, bem como sistema de hospedagem, rede, banco de dados, servidor, segurança de dados, UX, entre outros conceitos.
