Na avaliação deste módulo, você deverá elaborar e entregar um Plano de Integração e Entrega Contínua para o projeto em desenvolvimento na ação de extensão (Cidade Virtual).

🎯 Diferentemente da atividade de checkpoint, este plano deverá considerar:

  • Um plano amplo que vise a automação de diversas atividades passíveis de automação pela equipe de desenvolvimento.
  • A melhoria da qualidade por meio de entregas mais consistentes e frequentes.
  • Para além da automação de atividades simples (build e teste de software), considerar a automação do processo de entrega ou implantação, analisando as características da aplicação proposta.
  • Refletir também sobre a integração de novas tecnologias e ferramentas, baseadas ou não em Inteligência Artificial, que possam agregar valor às atividades desenvolvidas.

insights Resumo do Plano de CI/CD
  • Objetivo geral: Automatizar o ciclo de desenvolvimento do Cidade Virtual, desde o commit até o deploy em produção, garantindo qualidade, segurança e agilidade nas entregas.
  • Processos automatizados: Lint/Format (Husky), Testes unitários e integração (Jest + Supertest), Verificação de segurança (npm audit), Análise estática (SonarCloud), Deploy (Vercel via GitHub Actions).
  • Integração com IA: CodeRabbit para revisão automatizada de pull requests e GitHub Copilot para sugestões em tempo real.
  • Ferramentas selecionadas: GitHub Actions (CI), Vercel (CD), SonarCloud (qualidade), Husky (hooks), CodeRabbit (IA).
  • Cronograma: 4 semanas (32h) - implementação incremental: (1) conformidade + testes unitários, (2) testes integração + segurança, (3) SonarCloud + CD homologação, (4) IA + CD produção.
  • Benefícios esperados: Redução de 70% do tempo de deploy manual, detecção precoce de defeitos, padronização do código, maior confiança para a comunidade.
