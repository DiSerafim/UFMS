insights Resumo do Plano de Desenvolvimento Seguro
  • Características da aplicação: Plataforma web MERN para conexão comunitária no bairro Cabanagem (Belém/PA). Armazena dados pessoais de moradores e comerciantes.
  • Aspectos de segurança críticos: Confidencialidade de dados, autenticação robusta, proteção contra ataques comuns (injeção, XSS, força-bruta).
  • Objetivos: Implementar controles de segurança alinhados ao OWASP Top 10; garantir a tríade CID; reduzir riscos para a comunidade.
  • Práticas por camada: HTTPS (infraestrutura), bcrypt + JWT (aplicação), logs estruturados (auditing), OWASP ZAP (ferramentas), validação de entrada (API).
  • Governança: Revisão de segurança quinzenal, checklist OWASP ASVS, dependências monitoradas com npm audit.
  • Cronograma: 5 semanas (32h) - implementação incremental começando por segurança de acesso.
