Materiais

Neste módulo, você aprendeu sobre os conceitos de containers e docker, além de conhecer alguns provedores de serviços na nuvem e seus serviços oferecidos.

Neste fórum, iremos debater sobre como você interage com os serviços oferecidos pela plataforma Docker.

Dessa forma, como último desafio desta disciplina:

  • (1) fazer o download da plataforma Docker Desktop ✅
  • (2) instalar na sua máquina ✅
  • (3) configurar essa plataforma ✅
  • (4) executar um comando Docker (deve ser um dos exemplos da aula do módulo 5, unidade 2 ou uma aplicação que você baixou da internet) ✅

Conteúdo

Descreva em apenas um parágrafo como foi sua experiência em executar Docker.

Resolução.

A experiência foi interessante, após instalar, executei o comando 

sudo docker container ls -a
para listar todos os containers e depois criei um novo container usando o comando 
docker run -d -p 8080:80 ubuntu
que iniciou o servidor web e foi possível acessar o nginx no navegador através do localhost. É fácil de usar container para testar e rodar os serviços de forma rápida e isolada.
