Resolução.

            Tipo de serviço ↓                        Mecanismo de proteção (criptografia) ↓
            Acesso por Wi-Fi	                     → AES-256 (1) chave simétrica
                                                    Redes Wi-Fi, AES (Advanced Encryption Standard) é o padrão de criptografia mais seguro e comum, utilizado em WPA2 e WPA3. AES utiliza uma chave simétrica, a mesma chave é usada para criptografar e descriptografar os dados.

            Ambiente Virtual de Aprendizagem (AVA)   → RSA-2048 (2) chave assimétrica
                                                    O RSA-2048 é uma criptografia de chave pública, onde uma chave pública encripta e uma chave privada decripta os dados.
            Assinatura Digital	                     → SHA-256 (3) Hash
                                                    A SHA-256 é uma função hash que gera uma "impressão digital" única dos dados. Em assinaturas digitais, é utilizada para garantir que o conteúdo não foi alterado, pois mesmo uma pequena mudança nos dados originais gera um hash completamente diferente.
            Certificado Digital	                     → RSA-2048 (2) chave assimétrica
                                                    RSA-2048 para garantir a identidade de um servidor ou usuário. A criptografia assimétrica RSA permite que esses certificados criem um canal seguro para a troca de informações, autenticando os servidores e evitando fraudes, especialmente em conexões HTTPS.
            Comércio Eletrônico	                     → AES-256 (1) chave simétrica
                                                    AES-256 é usado para proteger os dados financeiros dos clientes. A criptografia simétrica AES é eficiente para proteger grandes volumes de dados trocados rapidamente, garantindo que informações sensíveis, como dados de cartões de crédito.
            E-mail                                   → RSA-2048 (2) chave assimétrica
                                                    RSA-2048 é utilizado para proteger a autenticação e o tráfego de dados entre os servidores e clientes de e-mail. RSA permite o uso de chaves públicas para garantir que somente o destinatário com a chave privada correspondente possa ler a mensagem.
            Rede de Celular                          → AES-128 (1) chave simétrica
                                                    AES-128 para proteger a comunicação. Embora tenha um tamanho de chave menor, o AES-128 ainda é bastante seguro e rápido, sendo suficiente para os protocolos de criptografia nas redes 4G e 5G, como o LTE.
            Sistema Bancário	                     → MFA (4) autenticação
                                                    MFA (Multi-Factor Authentication) é um mecanismo de autenticação adicional para reforçar a segurança. A MFA combina senhas com outros fatores, como autenticação por biometria, tokens de SMS ou aplicativos autenticadores, proporcionando uma camada extra de proteção.
