Cliente

O cliente é o dispositivo ou programa que faz solicitações a um servidor para acessar serviços ou informações. Ele é o lado que consome o serviço.

  • Exemplo com LinkedIn/Facebook: Quando você abre o LinkedIn ou Facebook no navegador ou no aplicativo, seu dispositivo age como cliente. Ele solicita as postagens, notificações, mensagens e outras informações que estão armazenadas nos servidores dessas plataformas.
Servidor

O servidor é o dispositivo ou programa que recebe as solicitações do cliente, processa essas requisições e envia as informações ou serviços de volta ao cliente.

  • Exemplo com GitHub: O servidor do GitHub armazena o código, histórico de commits, issues, pull requests, entre outros. Quando o cliente (seu VSCode, navegador ou GitHub Desktop) solicita algum desses dados, o servidor responde enviando essas informações.
