Neste módulo 5, você aprendeu sobre conceitos de arquitetura de microsserviços em nuvens computacionais para os conceitos de containers e docker, além de exemplos de provedores e seus serviços.

Neste Checkout de Presença, você verificará os conhecimentos acumulados em 5 questões de avaliação.

Resolução: Questionário ✅ ❌

Pergunta 1

Docker Hub® é o repositório Git oficial do Docker® que permite versionar e hospedar imagens privadas e públicas.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Pergunta 2

Container como um Serviço (CaaS) é uma plataforma de hospedagem baseada em nuvem, perfeita para gerenciar seus containers.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: b. Nuvem cirrus. ✅

Resolução:

  • Container como um Serviço (CaaS) é um modelo de serviço em nuvem que permite aos usuários implantar, gerenciar e escalar contêineres. Essa plataforma é ideal para gerenciar contêineres, fornecendo a infraestrutura e as ferramentas necessárias para gerenciar contêineres de forma eficiente, o que facilita o desenvolvimento e a operação de aplicativos em contêineres.

Pergunta 3

Arquitetura Docker® não executa solicitações como em uma arquitetura cliente-servidor.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ✅

Resolução:

  • A arquitetura Docker, assim como a arquitetura cliente-servidor, é baseada em serviços que podem se comunicar entre si. No Docker, os contêineres podem agir como clientes ou servidores, enviando e recebendo solicitações entre si. A comunicação pode ocorrer por meio de redes Docker, onde contêineres podem se conectar uns aos outros para troca de dados e execução de serviços, similar ao funcionamento de uma arquitetura cliente-servidor.

Pergunta 4

Na arquitetura Docker®, as interfaces de (Docker API + Docker CLI) solicitam a execução de comandos para o Daemon Docker (dockerd), que recebe, processa e responde, como uma arquitetura Cliente-Servidor.

Resposta: Verdadeiro. ✅

Pergunta 5

Na arquitetura Docker®, as interfaces de (Docker API + Docker CLI) solicitam a execução de comandos para o Daemon Docker (dockerd), que recebe, processa e responde, como uma arquitetura Cliente-Servidor.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Resolução:

  • Na arquitetura Docker, a Docker API e a Docker CLI atuam como clientes que enviam solicitações ao Daemon Docker (dockerd). O daemon processa essas solicitações e executa as operações necessárias, funcionando assim de maneira semelhante a uma arquitetura Cliente-Servidor. O daemon é responsável por gerenciar contêineres, imagens e redes, e ele responde às solicitações feitas pela API ou pela linha de comando.
