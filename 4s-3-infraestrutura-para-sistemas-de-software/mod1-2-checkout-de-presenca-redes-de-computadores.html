Pergunta 1

A internet das coisas (IoT) está relacionada aos equipamentos eletrônicos inteligentes que podem ser configurados e controlados pela internet, um que não se enquadra em IoT é:

Escolha uma opção:

  • a. Refrigerador
  • b. Ar condicionado
  • c. Interfone
  • d. Portão eletrônico
  • e. TV de tubo de raio catódico
Resposta correta: e. ✅

Resolução:

  • A Internet das Coisas (IoT) envolve dispositivos eletrônicos inteligentes que podem ser conectados à internet para serem controlados e monitorados remotamente. Uma TV de tubo de raio catódico é uma tecnologia antiga, que não tem capacidade de conectividade inteligente e não pode ser controlada ou monitorada pela internet.

Pergunta 2

O modelo peer-to-peer (P2P) não pode ser um modelo cliente-servidor.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Resolução:

  • O modelo peer-to-peer (P2P) permite que os dispositivos na rede atuem tanto como clientes quanto como servidores. Em um modelo cliente-servidor tradicional, há uma distinção clara entre o cliente (que solicita recursos) e o servidor (que fornece recursos). Já no modelo P2P, os "peers" compartilham recursos diretamente entre si, sem a necessidade de um servidor central, o que significa que cada nó pode atuar como cliente e servidor ao mesmo tempo.

Pergunta 3

As normas internacionais, como RFC (Request For Comment) definem os protocolos, exceto:

Escolha uma opção:

  • a. Internet Control Message Protocol (ICMP) - RFC 792
  • b. Internet Protocol (IP) - RFC 791
  • c. Transmission Control Protocol (TCP) – RFC 793
  • d. User Datagram Protocol (UDP) - RFC 768
  • e. Delirium of Protocol - RFC XXIV
Resposta: e. ✅

Resolução:

  • As RFCs (Request For Comments) são documentos oficiais que definem os protocolos e padrões usados na internet. As outras opções (ICMP, IP, TCP e UDP) são exemplos de protocolos reais definidos por RFCs. Entretanto, "Delirium of Protocol - RFC XXIV" é fictício e não corresponde a uma norma oficial.

Pergunta 4

Ao planejar seu projeto de rede, o plano de endereçamento vai definir:

Escolha uma opção:

  • a. Endereço de Logradouros, para identificar a localização da rede.
  • b. Número do CPF, para identificar o indivíduo dono da rede.
  • c. Números de CNPJ, para identificar a empresa dona da rede.
  • d. Números IPs, para identificar os dispositivos da rede.
  • e. Números de CEP, para identificar o bairro da rede.
Resposta: d. ✅

Resolução:

  • O plano de endereçamento em redes de computadores é responsável por definir os números IPs (Internet Protocol) que identificam de forma única cada dispositivo conectado à rede. Esses endereços IP permitem que os dispositivos possam se comunicar entre si dentro de uma rede local ou na internet.

Pergunta 5

A internet pode ser conhecida por outros nomes, exceto:

Escolha uma opção:

  • a. A rede internacional
  • b. As redes interligadas
  • c. A rede dos vizinhos
  • d. A rede mundial de computadores
  • e. As redes das redes
Resposta: c. ✅

Resolução:

  • A internet é frequentemente chamada de rede internacional, redes interligadas, rede mundial de computadores ou rede das redes, pois conecta múltiplas redes ao redor do mundo. "A rede dos vizinhos" não é um termo adequado.
