Pergunta 2

Protocolo de Roteamento é o mecanismo como os roteadores encaminham pacotes.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Resolução:

  • Um protocolo de roteamento define como os roteadores comunicam informações entre si para determinar o melhor caminho para encaminhar pacotes de dados pela rede. Esses protocolos estabelecem o processo de troca de informações sobre as rotas disponíveis, permitindo que os roteadores decidam a rota mais eficiente para o encaminhamento dos pacotes.

Pergunta 3

As formas de autenticação da identidade de um usuário podem ser, exceto:

Escolha uma opção:

  • a. Algo que o indivíduo faz (biometria dinâmica)
  • b. Algo que o indivíduo sabe (senha, PIN)
  • c. Algo que o indivíduo possui (token)
  • d. Algo que o indivíduo é (biometria estática)
  • e. Algo que o indivíduo possui na árvore de decisão
Resposta: e. ✅

Pergunta 4

O Enhanced Interior Gateway Routing Protocol (EIGRP) é um protocolo de roteamento Exterior Gateway Protocol (EGP) desenvolvido pela Cisco Systems® por meio do algoritmo de atualização por difusão.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ❌ Resposta: Verdadeiro. ✅

Resolução:

  • O Enhanced Interior Gateway Routing Protocol (EIGRP) é, na verdade, um protocolo de roteamento de gateway interno (IGP), não um protocolo de roteamento de gateway externo (EGP). Ele foi desenvolvido pela Cisco Systems e utiliza o algoritmo de atualização por difusão (DUAL) para calcular as melhores rotas. Diferente dos protocolos EGP, que conectam redes diferentes, os IGPs, como o EIGRP, são usados para roteamento dentro de uma mesma rede ou sistema autônomo.

Pergunta 5

O dispositivo de segurança Firewall analisa os cabeçalhos dos pacotes IP para, exceto:

Escolha uma opção:

  • a. IP de origem e/ou IP de destino.
  • b. Tipo de protocolo TCP ou UDP.
  • c. Os dados do pacote, quanto ao: formato, tamanho e conteúdo.
  • d. Portas de origem e/ou Porta de destino.
  • e. Se Tráfego de Entrada e/ou Tráfego de Saída.
Resposta: c. ✅

Resolução:

  • O firewall, como dispositivo de segurança, geralmente se concentra em analisar informações dos cabeçalhos dos pacotes, como IP de origem e destino, tipo de protocolo (TCP ou UDP), portas de origem e destino e a direção do tráfego (entrada ou saída). Ele não inspeciona o conteúdo completo dos dados do pacote, como formato, tamanho e conteúdo (o payload), pois essa análise profunda é feita por outros dispositivos, como sistemas de detecção e prevenção de intrusão (IDS/IPS).
