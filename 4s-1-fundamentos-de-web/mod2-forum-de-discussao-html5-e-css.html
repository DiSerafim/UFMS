Materiais

O HTML5 (W3C, 2018) é o mais novo padrão de linguagem e marcação de hipertexto. Um padrão é geralmente estabelecido por meio de alguma norma produzida por alguma entidade com reconhecimento para tal.

No caso do HTML, a entidade responsável por estabelecer o padrão é a W3C, sigla para World Wide Web Consortium. Não há tradução oficial do documento para a língua portuguesa, entretanto, é possível encontrar em diversos sites trechos ou documentos com traduções não oficiais.

Resolução.

Apresentação do Elemento "article" (4.3.2 The article element).

O elemento "article" é uma das novas tags introduzidas no HTML5, projetada para encapsular conteúdo que é independente e auto contido. A especificação da W3C(2018) define o "article" como um elemento destinado a conter um bloco de conteúdo que pode ser distribuído ou reutilizado de maneira independente.

Características do Elemento "article".

Conteúdo Independente:

  • O conteúdo dentro de um "article" é considerado auto suficiente e deve fazer sentido mesmo fora do contexto da página onde está inserido.

Reutilização:

  • É ideal para conteúdos que podem ser distribuídos ou republicados, como artigos de notícias, postagens de blog, fóruns, relatos de usuários, etc.

Estrutura Semântica:

  • O uso do "article" melhora a estrutura semântica da página, facilitando o entendimento por motores de busca de leitores de tela.
Exemplo de Uso

Artigo de Notícias:

            "article"
                "h2"Notícias sobre Tecnologia."/h2"
                "p"A Tecnologia está em constante evolução."/p"
                "p"Leia mais >>"/p"
            "/article"

Em páginas da web moderna o elemento "article" é frequentemente republicado. A estrutura semântica clara proporcionada pelo "article" ajuda a melhorar a acessibilidade e a SEO.

O "article" é um elemento poderoso que contribui significativamente para a criação de conteúdo semântico e estruturado na web, ele facilita a reutilização de conteúdo e melhora a experiência tanto para os usuários quanto para os mecanismos de busca.
