Pergunta 1

Na videoaula, Fundamentos de Internet e Web - Introdução às Redes de Computadores do professor Júlio Cezar Estrella é afirmado que: apesar de baseados no modelo OSI de referência o modelo de fato no qual a internet se baseia é o TCP/IP, essa afirmação é verdadeira ou falsa?

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Resolução:

  • O modelo OSI (Open Systems Interconnection) é um modelo teórico de referência que define uma arquitetura de rede com sete camadas. No entanto, a Internet se baseia principalmente no modelo TCP/IP (Transmission Control Protocol/Internet Protocol), que é um conjunto de protocolos de comunicação utilizados para interconectar dispositivos em redes de computadores. O modelo TCP/IP tem quatro camadas: Link, Internet, Transport e Application. Portanto, a Internet se baseia de fato no modelo TCP/IP, embora o modelo OSI seja utilizado como uma referência teórica.

Pergunta 5

De acordo com a definição de (MARINHO, 2019) sobre Client/Server Side, o Firefox é um elemento do Server Side.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ✅

Resolução:

  • De acordo com a definição de (MARINHO, 2019), o Firefox é um navegador web e, portanto, é um elemento do Client Side (lado do cliente). Ele é utilizado pelos usuários para acessar e interagir com os servidores web, mas não faz parte do lado do servidor (Server Side).
