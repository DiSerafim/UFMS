Conteúdo

Realize a seguinte atividade:

  • Após a leitura você conseguiria elaborar políticas de segurança para o seguinte problema: A Universidade SegurançaU está desenvolvendo um novo sistema para autenticação de diplomas e precisa estabelecer políticas de segurança tanto para o acesso ao sistema por parte dos usuários, como para o acesso pela rede. Além disso, políticas de segurança para a emissão dos diplomas são necessárias.
  • Como você desenvolveria as políticas de segurança necessárias para a Universidade SegurançaU?
  • Elabore um texto de 50 a 150 palavras em que apresente as suas políticas e como elas devem ser implementadas para que o sistema pretendido seja seguro.

Resolução

Sistema para autenticação de diplomas
  1. Usuários:
    • O acesso dos usuários deve ser com autenticação multifator (MFA) e senha complexa.
    • A conexão deve ser criptografada (TLS/HTTPS).
    • Deve aver controle de permissões por perfis.
  2. Acesso a rede:
    • O sistema deve ser protegido com firewalls configurado com regras de acesso.
    • Deve ser monitorado por um sistema de detecção de intruso (IDS/IPS)
    • O servidor deve ser segmentado da rede principal (divisão de uma rede em várias sub-redes).
  3. Emissão dos diplomas:
    • Deve ter assinatura digital com certificado válido.
    • Deve ter registro de logs, para auditoria.
    • Deve ter registro de hash criptografado para cada diploma.
    • Todas as políticas devem ser documentadas e revisadas periodicamente.
    • Deve ter controle de acesso para quem pode emitir os documentos.
