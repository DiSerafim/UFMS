Materiais

Neste módulo, você aprendeu sobre os principais conceitos de interface humano-computador, interface, interação, affordance, usabilidade, experiência do usuário e acessibilidade.

Imagine que você vá fazer a análise de um sistema que usa no seu dia a dia, para indicar algumas características positivas e negativas. Bom, é provável que você considere o ponto de vista de um usuário frequente do sistema, sem uma necessidade mais específica e com bons conhecimentos em informática básica.

Mas… e se esse sistema precisasse ser utilizado por uma pessoa com deficiência? Além das deficiências (física, motora, intelectual), pode haver necessidades específicas como, por exemplo, um usuário novato acessando o sistema pela primeira vez, ou um idoso com mobilidade reduzida, ou uma pessoa que fala uma língua diferente do português.

Conteúdo

Agora, faça o exercício de imaginar um usuário com alguma deficiência ou necessidade mais específica e compartilhe:

  • 1. Primeiro, especifique o sistema que está analisando e qual é o contexto de uso.
  • 2. As características desse sistema que, para um usuário “comum”, são positivas ou negativas, se manteriam verdadeiras para um usuário com uma necessidade mais específica? Há novas?
  • 3. Compartilhe conosco qual perfil de usuário você considerou e discuta como a interface e a interação poderiam ser melhoradas para atender às necessidades específicas dele.

Resolução.

Sistema escolhido e contexto de uso '99 Pop'.

Uso diariamente pois é o meu trabalho atualmente. O App tem funcionalidades como solicitação de viagens, pagamento, navegação, e histórico de viagens.

Características positivas e negativas para usuário comum e com necessidade específica.

Para usuários comuns, o ponto positivo seria a interface limpa e fácil de usar, com ícones intuitivos para navegação e solicitação de viagens. A localização do GPS é precisa as informações das corridas são acessíveis e rápidas.

Para usuários com necessidades mais específicas como uma pessoa com deficiência visual, as características podem não ser tão eficientes. A dependência da visualização de ícones pode ser um problema. O App tem integração com leitor de tela mesmo assim acredito que nem todas as áreas podem ser de facilmente acessadas por voz. Poderiam ampliar a acessibilidade e oferecer mais instruções por áudio para usuários com baixa visão.

Perfil de usuário considerado e melhorias.

O perfil de usuário seria uma pessoa com deficiência visual. Para melhorar a interface e interação do aplicativo, seria:

  1. Maior compatibilidade com leitores de tela:
    • Garantir que todos os elementos do aplicativo, como os botões, e notificações possam ser lidos corretamente.
  2. Instruções por voz:
    • Melhorar as instruções por voz, como a confirmação de destino e status da viagem.
  3. Tamanho de texto ajustáveis:
    • Permiti ajustes no tamanho do texto para assim facilitar a leitura de pessoas com pouca visão.
