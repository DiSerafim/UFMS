Materiais

Neste módulo, foram apresentadas duas estruturas de dados, a Tabela de Dispersão (Hash Table) e a Lista de Prioridades (Heap), sendo discutidas a eficiência dos algoritmos de inserção, remoção e busca.

Conteúdo

Agora vamos nos aprofundar nas discussões sobre essas duas estruturas de dados, e, para isso, responda às seguintes questões:
  1. Cite uma vantagem e uma desvantagem dos Heaps.
  2. Cite uma vantagem e uma desvantagem das Hash Tables.

1. Cite uma vantagem e uma desvantagem dos Heaps.

Vantagens:

Inserção e remoção de elementos, especialmente em heap binário ou fila de prioridade. As operações de inserção e remoção têm complexidade O(log n), eficiente para manter uma lista de prioridades.

Desvantagens:

Não suportam acesso eficiente a elementos arbitrários. Acessar um elemento específico, que não seja a raiz, requer uma pesquisa linear O(n).

2. Cite uma vantagem e uma desvantagem das Hash Tables.

Vantagens:

A velocidade das operações de busca, inserção e de exclusão podem ser realizadas em tempo constantes O(1) na média, assumindo uma função de hash bem distribuída e uma carga fator apropriada. Tornando a hash tables extremamente eficientes paras operações de pesquisa.

Desvantagens:

A gestão de colisões, que ocorrem quando dois fatores distintos têm o mesmo hash.Resolver colisões como encadeamento ou endereçamento aberto podem complicar a interpretação e o desempenho. Hash tables podem exigir mais memória do que outras estruturas.
