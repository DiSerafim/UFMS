Materiais

Agora você já tem conhecimento da base utilizada no algoritmo de classificação utilizado pelo Google, o PageRank. Descreva, com suas palavras, a ideia central utilizada pelo algoritmo, abrangendo os tópicos:

Conteúdo

  • Conceitos;
  • Estrutura de dados para representação;
  • Métrica/critério de avaliação.

Resposta:

A ideia é avaliar a relevância de uma página com base no número e na qualidade dos links que apontam pra ela. Os links são vistos como votos de confiança e uma página se torna importante se muitos links apontarem para ela.

Para representar o PageRank tem Vértices que representam páginas da web e Arestas que representam os links dessas páginas. Cada aresta tem uma direção. Cada página pode ter um valor inicial atribuído.

A métrica e critério de avaliação é descrito como Distribuição Inicial onde todas as páginas começam com o mesmo valor de PageRank. Distribuição de PageRank onde o PageRank de cada página é distribuído entre todas as páginas que ela aponta. Normalização onde o valor redistribuído é ajustado pela quantidade de links que contém na página. Iteração onde o processo é repetido várias vezes até que os valores de PageRank de todas as páginas se estabilizem.
