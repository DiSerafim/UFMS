## EMENTA:

Utilização prática de um SGBD. Índices, triggers, funções e procedimentos armazenados. Introdução a Conceitos de Processamento de Transações e Controle de Concorrência. Administração de Banco de Dados. Segurança e autorização em Banco de Dados. Integração de Banco de Dados à Web. Tópicos Avançados.

## OBJETIVO:

## Objetivo Geral:

Entender técnicas utilizadas por sistemas de gerenciamento de banco de dados, incluindo:

- Processamento de consultas SQL,
- Controle de transações (procedimentos armazenados e gatilhos) e
- Conceitos sobre Bancos de Dados NoSQL.

### Objetivos Específicos:

- Utilização prática de comandos SQL (definição e manipulação de dados)
- Criação de Visões de Banco de Dados
- Criação e execução de Procedimentos Armazenados e Transações
- Criação e execução de Gatilhos

## PROGRAMA:

### Módulo 1 – Utilização prática de um SGBD usando Comandos SQL

- **Unidade 1** - Comandos SQL (DDL e DML), Constraints
- **Unidade 2** - Visões e Índices

### Módulo 2 – Utilização prática de um SGBD usando Funções

**Unidade 1** - Funções e Procedimentos armazenados
**Unidade 2** - Triggers

### Módulo 3 – Introdução a Conceitos de Processamento de Transações e Controle de Concorrência

**Unidade 1** - Transações Begin, Commit e Rollback
**Unidade 2** - Mapeamento OR e Conexão com Aplicação com Banco de Dados

### Módulo 4 – Controle de Concorrência e Administração de Banco de Dados

**Unidade 1** - Segurança e Autorização em Banco de Dados
**Unidade 2** - Tarefas e Funções do Database Administrator (DBA)
