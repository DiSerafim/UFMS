# 📘 Plano de ensino - UFMS Digital

## Disciplina: Análise e Projeto de Software Orientado a Objetos
**Carga horária:** 68h
**Professor Especialista:** Luciano Édipo Pereira da Silva

---
## 📚 Ementa:
Revisão dos modelos de processo de desenvolvimento de software. Análise e especificação de requisitos de software. Métodos para análise e projeto de sistemas orientados a objetos. Padrões de projeto GRASP (General Responsibility Assignment Software Patterns). Linguagem de modelagem unificada. Normas para documentação. Ferramentas CASE. Análise, projeto e implementação de um software orientado a objetos.

---

## 🎯 Objetivos:

### Objetivo Geral:

Identificar e analisar os princípios, conceitos e métodos aplicados na análise e projeto de software orientado a objetos.

### Objetivos Específicos:

- Compreender os principais conceitos de orientação a objetos.
- Conhecer os principais métodos para análise de software orientado a objetos.
- Familiarizar-se com os principais métodos para projeto de software orientado a objetos.
- Planejar e realizar um projeto de software orientado a objetos.
