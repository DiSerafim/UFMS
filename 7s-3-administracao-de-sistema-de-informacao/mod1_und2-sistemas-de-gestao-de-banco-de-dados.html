💡 O que é um Sistema de Gestão de Banco de Dados?

Um sistema de gestão de banco de dados (Database Management System — DBMS ou SGBD) é um software específico usado para criar, armazenar, organizar e acessar dados a partir de um banco de dados (LAUDON e LAUDON, 2014).

Os bancos de dados são as ferramentas mais utilizadas para o armazenamento das informações e dos dados, seja em um servidor físico ou na nuvem. Surge assim a necessidade de ferramentas específicas que facilitem o trabalho na hora de estruturá-los para receber essas informações (OLIVEIRA, 2023).

🔗 SGBDs Relacionais

Chamamos popularmente de "banco de dados", mas na realidade são os SGBDs que gerenciam os bancos. Por padrão, utilizam a linguagem SQL para realizar consultas, o que traz vantagens como aprendizado, portabilidade, longevidade e liberdade de escolha.

dolphin

MySQL

Popular, open source, multiplataforma e compatível com diversas linguagens. Possui comunidade ativa e o MySQL Workbench para facilitar a administração. Ideal de aplicações simples a robustas.

cloud

Oracle

Surgiu nos anos 70. Possui várias edições focadas em empresas de médio e grande porte. Suporta múltiplos bancos de dados e oferece o SQL Developer como ferramenta gratuita de administração.

elephant

PostgreSQL

Open source, estável, escalável e com flexibilidade no uso de stored procedures. Multiplataforma, utiliza o pgAdmin (acessível via navegador) para facilitar a administração.

🚀 Bancos de Dados NoSQL

trending_up Por que o NoSQL surgiu?

Com a popularização da internet, redes sociais e dispositivos móveis, o volume de dados não estruturados cresceu exponencialmente. Bancos relacionais escalam, mas tornam-se custosos (máquinas e especialistas). O NoSQL surgiu para resolver questões de escalabilidade horizontal e custos de manutenção de Big Data (DEVMEDIA, 2023).

view_column

Cassandra (Colunar)

Armazenamento orientado a colunas, otimizando a leitura de grandes volumes de dados (OLAP). Desenvolvido pelo Facebook, é altamente escalável, de baixa latência e descentralizado.

description

MongoDB (Documentos)

Líder NoSQL. Armazena dados em formato JSON (BSON), sem necessidade de colunas pré-montadas. Possui baixa curva de aprendizagem, fácil escalabilidade horizontal e suporte a transações ACID.

hub

Neo4j (Grafos)

Otimizado para relacionamentos complexos entre dados. Utiliza a linguagem de consulta própria Cypher. Muito usado por empresas como Walmart e LinkedIn para análise de redes.

key

Redis (Chave-Valor)

Extremamente rápido, armazena dados na memória (RAM). Ideal para sistemas de cache, sessões e aplicações que exigem alta performance de leitura e escrita.

🧩 Componentes e Recursos de um Sistema de Informação

Relembrando O'Brien (2004), a construção de um modelo de informação requer habilidades que vão além da programação. Um SGBD é parte fundamental do recurso de Dados, que interage com os outros quatro recursos básicos:

  • 👥 Recursos Humanos: Usuários finais e especialistas em sistemas de informação (DBAs, desenvolvedores).
  • 💻 Recursos de Hardware: Servidores, máquinas e mídias de armazenamento.
  • ⚙️ Recursos de Software: O próprio SGBD, programas e procedimentos de acesso.
  • 🗄️ Recursos de Dados: Bancos de dados e bases de conhecimento estruturados ou não.
  • 🌐 Recursos de Rede: Meios de comunicação que permitem o acesso distribuído aos dados.
