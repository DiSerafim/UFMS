📋 Orientações para a Atividade

info Contextualização:

Neste módulo, você aprendeu os conceitos fundamentais da Análise Organizacional e explorou o uso de bases de dados públicas, com atenção à Lei Geral de Proteção de Dados (LGPD).

Para concluir este módulo e registrar sua presença, sua tarefa será identificar uma problemática em sua localidade, algo que você tenha observado no seu dia a dia, no seu bairro, escola, comunidade ou cidade.

📝 Estrutura da atividade

search 1. Identifique o problema

Observe sua localidade e encontre uma problemática real que mereça atenção. Pode ser sobre transporte público, infraestrutura urbana, segurança, saúde, educação, gestão de resíduos, entre outros.

storage 2. Busque fontes de dados

Identifique possíveis fontes de dados locais (relatórios da prefeitura, secretarias municipais) ou busque bases de dados online em portais como:

  • 📊 dados.gov.br
  • 📊 IBGE
  • 📊 Portal da Transparência
  • 📊 IPEA
  • 📊 CGE-MS

mic 3. Grave o podcast (até 3 min)

No áudio, você deve:

  • ✅ Apresentar o problema identificado
  • ✅ Citar o link da base de dados escolhida
  • ✅ Descrever brevemente o conteúdo da base
  • ✅ Justificar por que essa base é útil para a análise organizacional

cloud_upload 4. Envie o arquivo

Formato: MP3, WAV ou similar. Envie no espaço da tarefa aqui no AVA.

example Exemplo de roteiro para o podcast

Introdução (30 segundos): "Olá, meu nome é [seu nome] e estou cursando Análise Organizacional e Soluções Tecnológicas na UFMS. Neste podcast, vou apresentar um problema identificado na minha localidade..."

Problema (1 minuto): "O problema que identifiquei é a demora no atendimento nas UPAs do meu bairro. Muitos moradores relatam esperas de mais de 4 horas..."

Base de dados (1 minuto): "A base de dados que escolhi está disponível no DATASUS no link [inserir link]. Esta base contém informações sobre tempo de espera, número de atendimentos e perfil dos pacientes atendidos nas UPAs da região..."

Justificativa (30 segundos): "Esta base é útil para uma análise organizacional pois permite identificar os horários de pico, os dias com maior demanda e possíveis gargalos no atendimento, auxiliando na proposição de soluções tecnológicas como um dashboard de monitoramento ou um sistema de agendamento inteligente."

link Portal para gravação:

Veja aqui as orientações de como gravar e enviar seu podcast. Você pode utilizar ferramentas como gravador do celular, Anchor, Spotify for Podcasters, Audacity (gratuito) ou o próprio gravador do AVA.

✅ Checklist para envio

  • O problema identificado é relevante para a localidade?
  • A base de dados escolhida é pública e confiável?
  • O podcast tem duração de até 3 minutos?
  • O áudio apresenta o problema, o link da base, descreve o conteúdo e justifica a utilidade?
  • O arquivo está no formato MP3, WAV ou similar?
  • A gravação está clara e compreensível?
