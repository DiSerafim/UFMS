📈 1. Monitoramento de Software

timeline Conceito:

Monitoramento de software é a atividade contínua de acompanhar o desempenho, progresso e qualidade do projeto. Envolve a coleta de métricas, auditorias, relatórios e indicadores, baseando-se em dados reais para a tomada de decisão.

Técnicas de Monitoramento

speed Métricas de desempenho

Avaliam a eficiência operacional do sistema.

  • Tempo de resposta (latência)
  • Uso de CPU, memória e disco
  • Taxa de transferência (throughput)
  • Disponibilidade (uptime)
  • Taxa de erros (error rate)

analytics Métricas de processo

Analisam a eficiência do desenvolvimento.

  • Produtividade da equipe
  • Taxa de defeitos por módulo
  • Cobertura de testes
  • Dívida técnica (technical debt)
  • Tempo médio de resolução de bugs

event Acompanhamento de cronograma

Verificam o andamento do projeto.

  • Marcos (milestones) alcançados
  • Entregas parciais realizadas
  • Cumprimento de prazos
  • Velocidade da equipe (sprints)

verified_user Auditorias e revisões técnicas

Garantem conformidade e qualidade.

  • Revisões de código (code review)
  • Auditorias de segurança
  • Checklists de conformidade (ISO, LGPD)
  • Documentação técnica

🛠️ 2. Ferramentas de Monitoramento - Desempenho

dashboard Grafana + Prometheus Open Source

Prometheus: Sistema de monitoramento que coleta métricas em tempo real de aplicações, servidores e bancos de dados. Utiliza um modelo pull (busca ativa) e armazena séries temporais.

Grafana: Plataforma de visualização que consome dados do Prometheus e gera dashboards interativos com gráficos, alertas e mapas de calor.

Principais métricas monitoradas:

  • Tempo de resposta das APIs (percentis 50, 95, 99)
  • Uso de CPU e memória por serviço
  • Taxa de requisições por segundo (RPS)
  • Latência de conexão com banco de dados
Exemplo de query Prometheus (PromQL): 
# Taxa de requisições HTTP por segundo
rate(http_requests_total[5m])

# Latência média (p95) de requisições
histogram_quantile(0.95, 
  http_request_duration_seconds_bucket)

🔍 3. Ferramentas de Monitoramento - Qualidade de Código

code SonarQube Open Source

Plataforma de análise estática de código que avalia qualidade, segurança e manutenibilidade. Suporta mais de 25 linguagens (Java, Python, JavaScript, C#, Go, etc.).

Métricas analisadas:
  • 🐛 Bugs: erros de lógica e comportamento
  • 🔒 Vulnerabilidades: falhas de segurança
  • 💣 Code Smells: más práticas que prejudicam manutenção
  • 📊 Cobertura de testes: percentual de código testado
  • 🧮 Duplicação: código repetido
  • 📈 Dívida técnica: tempo estimado para correção
Exemplo de configuração (sonar-project.properties): 
sonar.projectKey=projeto_vias
sonar.sources=src/
sonar.language=python
sonar.python.coverage.reportPaths=coverage.xml
sonar.coverage.exclusions=**/tests/**

📅 4. Acompanhamento de Cronograma

board HacknPlan Freemium

Ferramenta de gestão de projetos com foco em desenvolvimento de software, usando sistema de boards estilo Kanban. Especialmente útil para projetos multidisciplinares.

Funcionalidades principais:
  • 📋 Kanban com colunas personalizáveis (To Do, In Progress, Review, Done)
  • 🏷️ Categorização por áreas (front-end, back-end, design, testes)
  • 📊 Métricas de progresso (burndown chart, velocity)
  • 🔗 Integração com repositórios Git
  • 📎 Anexos e comentários por tarefa
Métricas geradas:
  • 📈 Velocidade da equipe (pontos por sprint)
  • ⏱️ Lead time (tempo entre criação e conclusão)
  • 🔄 Cycle time (tempo efetivo de trabalho)
  • 📉 Burndown (tarefas restantes vs tempo)

📋 5. Auditorias e Revisões Técnicas

assignment Redmine Open Source

Sistema flexível de gestão de projetos com plugins específicos para auditoria, conformidade com ISO 19011 e ABNT NBR ISO/IEC 27001.

Funcionalidades para auditoria:
  • ✅ Checklists formais por auditoria
  • 📝 Registro de não conformidades com níveis de severidade
  • 📎 Versionamento de documentos anexados
  • 📊 Relatórios PDF customizáveis
  • 🔒 Trilha de auditoria (log de ações)
Integração com normas:
  • ISO 19011 (Diretrizes para auditoria)
  • NBR ISO/IEC 27001 (Segurança da informação)
  • ISO 9001 (Gestão de qualidade)

✅ 6. Validação de Software

verified Conceito:

Validação é o processo de verificar se o software atende aos requisitos especificados e às necessidades do usuário. Enquanto a verificação responde "construímos o produto certo?", a validação responde "construímos o produto certo para o usuário?".

Técnicas de Validação

check_circle Testes de Aceitação

Verificam se o sistema atende aos critérios de aceitação definidos com o cliente/usuário. Simulam o uso real do sistema.

Exemplo: "Ao preencher todos os campos obrigatórios e clicar em 'Enviar', o usuário deve ver uma mensagem de confirmação."

build Testes de Sistema

Verificam se todos os módulos funcionam juntos corretamente (teste end-to-end). Inclui testes de integração, desempenho e segurança.

Exemplo: "Ao fazer login, o sistema carrega corretamente o painel com dados do usuário recuperados do banco."

groups Inspeções e Revisões

Análises manuais ou semiautomáticas feitas por revisores humanos (pares, especialistas). Identificam defeitos precocemente, reduzindo custos de retrabalho.

Tipos: Revisão de código, inspeção de requisitos, revisão de design, walkthroughs.

🧪 7. Ferramentas de Validação - Selenium

web Selenium Open Source

Framework para automação de testes de aplicações web. Suporta múltiplos navegadores (Chrome, Firefox, Edge, Safari) e linguagens (Python, Java, C#, JavaScript, Ruby).

Selenium WebDriver: API para controle programático do navegador. Ideal para testes automatizados complexos.
Selenium IDE: Extensão de navegador para gravação e playback de testes. Boa para prototipação rápida. 
# Exemplo de teste com Selenium WebDriver (Python)
from selenium import webdriver
from selenium.webdriver.common.by import By

# Inicializa o driver do Chrome
driver = webdriver.Chrome()

# Teste de Aceitação: cadastro de reporte no dashboard
driver.get("https://viasdacabanagem.com.br/reportar")

# Preenche o formulário
driver.find_element(By.ID, "via").send_keys("Av. Brasil")
driver.find_element(By.ID, "problema").send_keys("Buraco")
driver.find_element(By.ID, "submit").click()

# Verifica a mensagem de confirmação
mensagem = driver.find_element(By.CLASS_NAME, "sucesso").text
assert mensagem == "Reporte enviado com sucesso!"

driver.quit()

🏘️ Aplicação Prática: Monitoramento e Validação no Projeto "Vias da Cabanagem"

apartment Estratégia de Monitoramento e Validação

🔍 Monitoramento:

  • Tempo de resposta do dashboard: Monitorado via Prometheus + Grafana, com alerta se ultrapassar 3 segundos
  • Taxa de falhas no recebimento de reportes: Monitorada via logs do back-end (Node.js)
  • Disponibilidade da API: Verificada a cada minuto via heartbeat endpoint
  • Qualidade do código: Analisada com SonarQube a cada push no repositório GitHub
  • Progresso do projeto: Acompanhado via HacknPlan (board Kanban com sprints semanais)

✅ Validação:

  • Testes de Sistema: Automatizados com Selenium WebDriver (Python) para verificar integração front-end/back-end
  • Testes de Aceitação: Realizados com 10 moradores do bairro, simulando reporte de problemas no dashboard
  • Inspeções de código: Revisão por pares de cada Pull Request antes do merge

✅ Checklist para Monitoramento e Validação

Definição de métricas de desempenho (tempo de resposta, CPU, memória)
Configuração de ferramenta de monitoramento (Prometheus + Grafana)
Análise de qualidade de código (SonarQube)
Acompanhamento de cronograma (HacknPlan ou similar)
Definição de critérios de aceitação com cliente/usuário
Elaboração de casos de teste automatizados (Selenium)
Execução de testes de sistema e aceitação
Realização de inspeções e revisões técnicas
Documentação dos resultados (relatórios de teste, logs de auditoria)
