Cada valor corresponde ao lado de um triângulo e a partir dos valores informados na entrada o programa deverá informar qual o tipo de triângulo formado: equilátero — caso os três lados sejam iguais; isósceles — caso o triângulo possua dois lados iguais; e escaleno — caso os três lados sejam diferentes.

    •                 #programa Triangle
                #  Leitura dos lados
                print("Problema dos Triangulos\n")
                ladoA = input('Digite o lado A: ')
                ladoB = input('Digite o lado B: ')
                ladoC = input('Digite o lado C: ')
                #verifica se os valores digitados são válidos
                if (ladoA.isdigit() and ladoB.isdigit() and ladoC.isdigit()):
                    #testa os lados dos triangulos
                    if (ladoA == ladoB) and (ladoA == ladoC):
                    print("Triangulo EQUILATERO")
                    elif ((ladoA == ladoB) or (ladoA == ladoC) or (ladoB == ladoC)):
                    print("Triangulo ISOCELES")
                    else:
                    print("Triangulo ESCALENO")    
                else:
                    print("Ha pelo menos uma entrada invalida!!!")
