Pergunta 1

A preocupação com a Qualidade de Software permeia todo o desenvolvimento dele, sendo que os requisitos são a matéria-prima para as atividades de verificação, validação e teste de software.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • A qualidade de software deve ser considerada desde o início do desenvolvimento, e os requisitos são a base para todas as etapas de verificação, validação e testes.
    • Verificação garante que o produto está sendo construído corretamente, com base nos requisitos.
    • Validação garante que o produto atende aos requisitos do usuário.
    • Testes usam os requisitos como referência para definir os casos de teste e avaliar se o software está correto.

Pergunta 2

Relacione corretamente as perguntas-chave com as definições de Verificação e Validação.

                Estamos construindo o produto certo? (...)
                Estamos construindo corretamente o produto? (...)

Opções: Verificação, Validação.

Resposta: ✅

📌 Explicação:

                Estamos construindo o produto certo? Validação
                Estamos construindo corretamente o produto? Verificação
  • Validação verifica se o produto final atende às necessidades dos usuários e aos requisitos funcionais e não funcionais.
    • 👉 Foco no “o que” está sendo entregue.
  • Verificação verifica se cada etapa do desenvolvimento está sendo feita corretamente, conforme os documentos e especificações.
    • 👉 Foco no “como” está sendo feito.

Pergunta 3

O grupo de teste só se envolve no projeto quando a fase de teste no processo de desenvolvimento estiver prestes a se iniciar.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ✅

📌 Explicação:

  • O grupo de teste não deve se envolver apenas no final do processo de desenvolvimento. Pelo contrário, as boas práticas de Engenharia de Software recomendam que as atividades de teste comecem o quanto antes, desde as fases iniciais do projeto, como análise de requisitos e design.
  • Envolver o grupo de testes desde o início permite:
    • Melhor entendimento dos requisitos;
    • Planejamento mais eficaz dos testes;
    • Detecção precoce de erros, reduzindo custos e retrabalho.

Pergunta 4

A busca pela qualidade de software é o caminho para reduzir prazos, custos e insatisfações no processo de desenvolvimento, garantindo mais previsibilidade e melhores resultados.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • Buscar qualidade de software desde o início do desenvolvimento permite:
    • Redução de prazos, pois diminui retrabalho;
    • Redução de custos, ao evitar correções tardias e falhas em produção;
    • Menor insatisfação, tanto dos usuários quanto da equipe de desenvolvimento;
    • Mais previsibilidade, com processos mais bem definidos e controlados;
    • Melhores resultados, entregando um produto mais estável, funcional e alinhado aos requisitos.

Pergunta 5

Qualidade de Software significa conformidade com requisitos funcionais e de desempenho, padrões de desenvolvimento documentados e características implícitas esperadas de todo software profissionalmente produzido.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • A qualidade de software está diretamente relacionada à:
    • Conformidade com requisitos funcionais e de desempenho
      • o que o software deve fazer e como deve se comportar;
    • Aderência a padrões de desenvolvimento documentados
      • boas práticas, normas técnicas, arquitetura etc.;
    • Atendimento a características implícitas, como segurança, usabilidade, manutenibilidade e confiabilidade — que são esperadas mesmo que não estejam sempre detalhadas nos requisitos.

Pergunta 6

Evento notável no qual o sistema viola suas especificações.

  • a. Defeito.
  • b. Erro.
  • c. Falha.
  • d. Nenhuma das alternativas anteriores.
Resposta: c. ✅

📌 Explicação:

  • Erro: é uma ação humana ou informação incorreta que pode levar a um defeito no software.
  • Defeito (ou bug): é uma falha no código ou no design que pode causar funcionamento incorreto.
  • ✅ Falha: é o comportamento observável do sistema que viola suas especificações, ou seja, quando algo dá errado durante a execução do software.

Pergunta 7

Não devemos esperar até a fase de teste de software para remover os defeitos, porque a estratégia de teste exige a remoção antecipada dos defeitos.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • A estratégia moderna de teste de software defende que os defeitos devem ser identificados e removidos o mais cedo possível no ciclo de desenvolvimento, preferencialmente ainda nas fases de requisitos, análise ou design.
  • Essa abordagem traz diversos benefícios:
    • Reduz custos com correções (corrigir no início é muito mais barato);
    • Evita propagação de erros para fases seguintes;
    • Melhora a qualidade final do produto;
    • Aumenta a produtividade da equipe.

Pergunta 8

Qual atividade examina o comportamento do produto por meio da sua execução?

  • a. Validação.
  • b. Verificação.
  • c. Teste de Software.
  • d. Nenhuma das alternativas anteriores.
Resposta: c. ✅

📌 Explicação:

  • Teste de Software é a atividade que executa o programa com o objetivo de encontrar erros e verificar se o comportamento do software está de acordo com o esperado.

Pergunta 9

Qual atividade assegura consistência, completitude e corretitude do produto em cada fase e entre fases do desenvolvimento?

  • a. Validação.
  • b. Verificação.
  • c. Teste de Software.
  • d. Nenhuma das alternativas anteriores.
Resposta: b. ✅

📌 Explicação:

  • Verificação é a atividade que busca assegurar que o software está sendo construído corretamente, com foco na consistência, completude e corretude dos artefatos em cada fase do desenvolvimento e também entre as fases.
    • Exemplo: revisar se os documentos de requisitos estão completos, ou se o design está de acordo com os requisitos.

Pergunta 10

Item de informação ou estado de execução inconsistente.

  • a. Defeito.
  • b. Erro.
  • c. Falha.
  • d. Nenhuma das alternativas anteriores.
Resposta: b. ✅

📌 Explicação:

  • Erro: é um item de informação ou estado de execução inconsistente, geralmente causado por uma falha humana, como um engano ao escrever código, interpretar requisitos ou projetar o sistema.
