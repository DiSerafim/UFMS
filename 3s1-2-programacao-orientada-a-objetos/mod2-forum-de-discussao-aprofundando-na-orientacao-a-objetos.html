1. Por que ao programar um código-fonte que faz uso de vetores (arrays) conseguimos acessar membros da classe Object da API Java?

Em Java, todos os arrays são objetos. Como resultado, os arrays herdam métodos da classe Objeto, como toString(), equals() e hashCode(). Isso significa que você pode acessar os métodos da classe Object em arrays, porque eles são objetos.

2. Quando um objeto não tem mais referências para ele, o que acontece com ele?

Significa que ele não pode mais ser acessado pelo programa. Em Java, o garbage collector é responsável por identificar e liberar a memória ocupada por objetos que não tem mais referência para eles.

O Garbage Collector executa em segundo plano e libera memória ocupada por esses objetos não utilizados, tornando-a disponível outros objetos.

3. Qual é a função dos Pacotes? Como é melhor usá-los?

Os pacotes em Java são usados para organizar classes relacionadas em um único local.

Eles ajudam a evitar conflitos de nomeação entre classes de diferentes bibliotecas ou projetos.

Além disso, os pacotes fornecem controle de acesso, permitindo que você especifique quais classes são acessíveis de fora do pacote.

para usar um pacote em Java é preciso importá-lo em seu código usando declaração import. Isso permite que você use classes do pacote em seu código sem ter que qualificar o nome da classe com o nome do pacote toda vez que você utiliza.
