1. Quais são as limitações de cada coleção? Quando devemos usar uma ou outra?

  • ArrayList:
      • Eficiente para acessar elementos por índice, a inserção e remoção de elementos podem ser lentas, devido ao deslocamento de elementos (em grandes conjuntos).
  • LinkedList:
      • Eficiente para inserção e remoção de elementos no início e no fim da lista, o acesso aleatório aos elementos pode ser lento percorrer a lista a partir do início ou do fim.
  • HashMap:
      • Eficiente para buscar elementos por chave, não garante a ordem dos elementos e não permite chaves duplicadas.
  • TreeMap:
      • Mantém os elementos ordenados de acordo com a chave, pode ser menos eficiente para operações de busca, inserção e remoção.

2. Como seriam os softwares reais sem tratamento de exceção? Qual seria o impacto para os usuários finais?

Os erros seriam propagados diretamente para os usuários finais de maneira controlada, resultando em falhas de aplicativos e uma experiência ruim para o usuário.

Tratando as exceções permite capturar e gerenciar erros de forma adequada.

3. Que tipos de arquivos podem ser manipulados no Java?

  • Arquivos de texto:
    • Podem ser lidos, gravados usando classes como FileReader, FileWriter, BufferedReader e BufferedWriter.
  • Arquivos de binários:
    • Podem ser lidos, gravados usando classes como FileInputStream, FileOutputStream, DataInputStream e DataOutputStream.
  • Arquivos de CSV(Valores Separados Por Virgula):
    • Podem ser manipulados usando classes como BufferedReader e BufferedWriter
  • Arquivos de JSON e XML:
    • Para manipula-los, podem ser usadas bibliotecas como Gson para JSON e JAXB para XML
