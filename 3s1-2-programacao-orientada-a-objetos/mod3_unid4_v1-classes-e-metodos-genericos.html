Classes e Métodos Genéricos.

Pilha de Inteiros.

                class PilhaVInt{
                    int[] v = new int[100];
                    int top = 0;
                    
                    void push(int x) {
                        v[top++]=x;
                    }

                    int pop(){
                        return v[--top];
                    }

                    //outros códigos...
                    public static void main(String[] s){
                        PilhaVIntp = new PilhaVInt();
                        p.push(10);
                    }
                }

Criando suas Classes usando Generics.

  • É possível criar a sua própria classe e adicionar elementos genéricos, que só vão ter seu tipo definido em runtime;
  • Só definir os tipos genéricos entre <> separados por vírgula após a definição da classe;
  • Ainda é possível definir se o tipo é filho de alguma classe específica usando a palavra extends para cada tipo definido ou implements para uma interface.

Exemplo 1:

            class PilhaVetor{
                T[] v = (T[])new Object[100];
                int top = 0;
                
                void push(T x) {
                    v[top++]=x;
                }

                T pop(){
                    return v[--top];
                }

                //outros códigos...
                public static void main(String[] args) {
                    PilhaVetor String  p = new PilhaVetor String();
                    p.push("Texto");
                    PilhaVetor Integer p = new PilhaVetor Integer();
                    p.push(10);
                }
            }
