Os pontos positivos do Paradigma de Programação Orientado a Objetos;
  • A reutilização do código, dividir o programa em classes e objetos, facilidade em desenvolver e entender o código e sua manutenção.

    • O que é uma classe;
    • Uma classe é uma estrutura que define o comportamento e os atributos de objetos relacionados. Ela serve como um modelo para a criação de objetos.
    • Por exemplo, uma classe "Carro" pode ter atributos como cor, modelo e ano, e métodos como ligar(), desligar() e acelerar().

    O que é um objeto;
    • Um objeto é uma instância específica de uma classe. Ele representa uma entidade ou conceito do mundo real e tem seus próprios atributos e métodos.
    • No exemplo da classe "Carro", um objeto seria um carro específico com uma cor, modelo e ano específicos.

    Um exemplo de classe e objeto;

    Uma classe é uma estrutura que define o comportamento e as propriedades de um objeto. Ela serve como um "molde" para criar objetos.

    Dentro da classe Carro, definimos três atributos: cor, modelo e ano, que representam as características de um carro.

    Em seguida, temos o método exibirInfo(), que é responsável por exibir as informações do carro na tela.

    Para criar um objeto a partir desta classe, utilizamos o seguinte trecho de código:

                Carro meuCarro = new Carro();

    meuCarro é uma variável que representa um objeto do tipo Carro. Utilizamos o operador new para criar uma nova instância da classe Carro.

    Código de exemplo em tela da classe e objeto; 
                // Definição da classe Carro
            class Carro {
                // Atributos
                String cor;
                String modelo;
                int ano;

                // Método para exibir informações do carro
                void exibirInfo() {
                    System.out.println("Cor: " + cor + ", Modelo: " + modelo + ", Ano: " + ano);
                }
            }

            // Criando e utilizando um objeto da classe Carro
            public class Main {
                public static void main(String[] args) {
                    // Instanciando um objeto da classe Carro
                    Carro meuCarro = new Carro();

                    // Definindo os atributos do objeto
                    meuCarro.cor = "Vermelho";
                    meuCarro.modelo = "Gol";
                    meuCarro.ano = 2020;

                    // Exibindo informações do carro
                    meuCarro.exibirInfo();
                }
            }
