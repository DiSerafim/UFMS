1. Quais os principais benefícios do Paradigma de Programação Orientado a Objetos?

A reutilização do código, dividir o programa em classes e objetos, facilidade em desenvolver e entender o código.

2. Qual é a relação entre Classe e Objeto? O que significa o termo instanciação?

Uma classe é um modelo ou protótipo para criar objetos, onde define variáveis e funções.

Um objeto é uma instância de uma classe, possui seus próprios valores para os atributos definidos na classe e pode invocar os métodos definidos na classe.

Instanciação é o processo de criação de um objeto a partir da classe.

Código em Java (AreaCirculo.java): 
            import java.util.Scanner;

            public class AreaCirculo {
                public static void main(String[] args) {
                    // Declaração de variáveis
                    double raio, area;
                    final double PI = 3.14159265;
            
                    // Entrada de dados
                    Scanner scanner = new Scanner(System.in);
                    System.out.print("Informe o raio da circunferência: ");
                    raio = scanner.nextDouble();
                    
                    // Cálculo da área
                    area = PI * raio * raio;
                    
                    // Saída de dados
                    System.out.println("A área da circunferência é: " + area);
                    
                    // Fechar o scanner
                    scanner.close();
                }
            }
