Introdução.

  • Java tem uma API específica para manipulação de objetos, denominada Collections;
  • É uma solução flexível para armazenar objetos, o que facilita bastante a vida do desenvolvedor;
  • A API Collections provê interfaces e classes para coleções;
  • Numa coleção, a quantidade armazenada de objetos não é fixa, como ocorre com arrays;
    • Seu tamanho pode aumentar automaticamente conforme são adicionados mais elementos.
  • Por meio destas coleções, é possível representar diferentes tipos de estruturas, como: listas, pilhas, filas, conjuntos e mapas.

Hierarquia das Collections (interfaces).

            Object
            └── AbstractCollection
                ├── Collection
                │   ├── AbstractSet
                │   │   ├── Set
                │   │   │   ├── HashSet
                │   │   │   └── TreeSet
                │   │   └── SortedSet
                │   ├── AbstractList
                │   │   ├── List
                │   │   │   ├── LinkedList
                │   │   │   ├── ArrayList
                │   │   │   └── Vector
                │   │   └── AbstractSequentialList
                │   └── Queue
                └── List
  • Object: Classe base de todas as classes em Java.
  • AbstractCollection: Classe abstrata que fornece uma implementação base para a interface Collection.
  • Collection: Interface que representa uma coleção de objetos, que pode ser uma lista, conjunto ou fila.
  • AbstractSet: Classe abstrata que fornece uma implementação base para a interface Set.
  • Set: Interface que representa um conjunto de elementos únicos, sem duplicatas.
  • HashSet: Implementação de Set que armazena elementos em uma tabela de dispersão, sem garantia de ordem.
  • TreeSet: Implementação de Set que mantém os elementos ordenados, geralmente em ordem natural ou usando um comparador personalizado.
  • SortedSet: Interface que estende Set e mantém os elementos ordenados.
  • AbstractList: Classe abstrata que fornece uma implementação base para a interface List.
  • List: Interface que representa uma lista ordenada de elementos.
  • LinkedList: Implementação de List que armazena os elementos em uma lista encadeada.
  • ArrayList: Implementação de List que armazena os elementos em um array redimensionável.
  • Vector: Implementação legada de List, semelhante a ArrayList, mas sincronizada.
  • AbstractSequentialList: Classe abstrata que fornece uma implementação base para listas sequenciais.
  • Queue: Interface que representa uma fila, seguindo o princípio FIFO (First-In-First-Out).

Hierarquia dos Maps (interfaces).

            Object
            └── AbstractMap
                ├── Map
                │   ├── HashMap
                │   ├── HashTable
                │   ├── TreeMap
                │   └── SortedMap
                │       └── N/A

Observe que um Map não é uma Collection (hierarquia - herança).

  • Object é a classe base de todas as classes em Java.
  • AbstractMap fornece uma implementação base para a interface Map.
  • Map é a interface que mapeia chaves para valores únicos.
  • HashMap é uma implementação de Map que usa uma tabela de dispersão para armazenar os pares chave-valor.
  • HashTable é uma implementação legada de Map, semelhante ao HashMap, mas sincronizada.
  • TreeMap é uma implementação de Map que mantém as chaves em ordem natural ou por meio de um comparador personalizado.
  • SortedMap é uma subinterface de Map que mantém as chaves ordenadas e oferece métodos adicionais de consulta baseados em ordenação.

A Interface List.

  • Uma lista é uma coleção de elementos arrumados em uma ordem linear:
    • É uma coleção em ordem (algumas vezes chamada de sequência);
    • Em geral, na ordem em que foram adicionados à lista;
  • Isto é, cada elemento tem um antecessor (exceto o primeiro) e um sucessor (exceto o último);
  • Normalmente implementada como Array ou Lista Encadeada.

List - Implementações.

  • ArrayList:
    • A implementação mais utilizada da interface;
    • É implementada sobre um vetor:
      • Logo tem as vantagens e desvantagens associadas: acesso randômico, portanto é rápida para pesquisa.
    • Não é sincronizado, isto é não tem segurança para programação concorrente (threads)
  • Vector: Ideal para acesso randômico, porém é sincronizado, logo, é mais lento.
  • LinkedList: ideal para acesso sequencial:
    • É implementada sobre uma lista ligada. Logo tem as vantagens e desvantagens associadas;
    • Não é sincronizado, logo, não suporta threads.

Exemplo List (ArrayList).

            public static void main(String[] args) {
                List list = new ArrayList();
                list.add(9);
                list.add(new Integer(8));
                list.add(new Integer(10));
                list.add(new Integer(6) + 3);
                list.add(7);

                for (int i = 0; i < list.size(); i++) {
                    int x = (int)list.get(i);//cast necessário
                    System.out.println(x);
                }
            }
Saída: 9 8 10 9 7
