Eventos.

  • Normalmente um usuário interage com uma interface gráfica do aplicativo para indicar a tarefa que o software deve realizar.
  • Quando um usuário interage com um componente GUI, essa interação é conhecida como evento.
  • Um evento geralmente guia o programa na realização de uma tarefa.
  • Guiam os fluxos de controle da aplicação, por sinais externos.
  • Eventos comuns:
    • Clicar/tocar;
    • Digitar em um campo de texto;
    • Selecionar um item de menu;
    • Fechar uma janela;
    • Arrastar um objeto.
  • No Android, uma Activity é responsável por controlar todos os eventos da tela.
  • Uma Activity é basicamente uma classe gerenciadora de UI (Interface com o Usuário).
  • Todo aplicativo Android começa por uma Activity.

Manipulação de eventos de clique.

  • Formas de desenvolver:
    • Através do XML no atributo onClick;
    • Implementação da interface na classe;
    • Implementação anônima da interface no método set;
    • Implementação anônima da interface como atributo.
  • Implementação pelo atributo onClick do componente:
    1. Selecionar o atributo;
    2. Definir nome do método;
    3. Acessar a classe Java da Activity em questão;
    4. Implementar métodos específicos para o evento de cada componente (ou um método geral).
  • Implementação da interface na classe:
    1. Tornar a classe uma implementação da interface OnClickListener (cuidar para escolher o da View);
    2. Implementar método onClick();
      • Torna-se o método único para todos os componentes.
    3. Selecionar, por meio de condições, o código do componente a
    4. capturar o evento;
    5. Apontar o setOnClickListener de cada componente para a própria classe (this).
