Pergunta 1

Para usar um componente do tipo EditText ou TextView por código em um arquivo .java:

  • a. É necessário referenciar o nome do componente no layout.
  • b. Não é possível.
  • c. É preciso referenciar a ordem do componente no layout.
  • d. É preciso referenciar o id do componente no layout.
  • e. Não é necessário nada de especial.
Resposta: d. ✅

📌 Explicação:

  • Para acessar um componente como EditText ou TextView no código Java, você precisa primeiro atribuir um android:id ao componente no layout XML e depois utilizar esse ID com o método findViewById() no seu código Java. Exemplo:
    • EditText meuEditText = findViewById(R.id.meu_edit_text);
    • meu_edit_text é o id definido no arquivo XML.
    • O método findViewById() busca esse componente pelo ID no layout.

Pergunta 3

Em qual dos seguintes casos NÃO é preciso tratar eventos de clique para um botão?

  • a. Quando o botão modifica o texto de um TextView.
  • b. Quando o botão abre uma nova Activity.
  • c. Quando o botão realiza uma operação de cálculo.
  • d. Quando o botão não utiliza ícones.
  • e. Quando o botão é usado apenas para exibir informações.
Resposta: d. ❌

📌 Explicação:

  • O tratamento de eventos de clique em um botão é necessário sempre que deseja que algo aconteça ao clicar nele, como:
    • Modificar um TextView → precisa de evento de clique.
    • Abrir uma nova Activity → precisa de evento de clique.
    • Realizar um cálculo → precisa de evento de clique.
    • Exibir informações (mesmo que seja só um Toast ou Dialog) → precisa de evento de clique.
  • Ter ou não ícones no botão não tem relação com o tratamento de eventos. Um botão pode ter um ícone apenas como parte do layout visual, mas isso não interfere na lógica de cliques. Portanto, não é necessário tratar o clique só porque o botão tem ou não tem um ícone.

Pergunta 5

Qual método é comumente usado para preparar um botão de forma que sejam tratados seus eventos de clique?

  • a. onButtonClick().
  • b. setOnClickListener().
  • c. setSensorListener().
  • d. onButtonPressed().
  • e. handleButtonClick().
Resposta: b. ✅
  • Esse método permite registrar um ouvinte (listener) que será chamado quando o botão for clicado. Exemplo:
                Button meuBotao = findViewById(R.id.meu_botao);
                meuBotao.setOnClickListener(new View.OnClickListener() {
                    @Override
                    public void onClick(View v) {
                        // Código a ser executado quando o botão for clicado
                    }
                });

Pergunta 6

O que o método setOnClickListener() espera como argumento?

  • a. Um objeto que implementa View.OnClickListener.
  • b. Um objeto Button.
  • c. Uma String.
  • d. Um objeto View.
  • e. Um objeto Spinner.
Resposta: a. ✅

📌 Explicação:

  • O método setOnClickListener() espera receber como argumento um objeto que implementa a interface View.OnClickListener, que define o método onClick(View v) para tratar o evento de clique.
                button.setOnClickListener(new View.OnClickListener() {
                    @Override
                    public void onClick(View v) {
                        // Código executado ao clicar no botão
                    }
                });

Pergunta 7

Se deseja-se que um botão responda a eventos de clique, qual das seguintes afirmações deve ser verdadeira?

  • a. O botão deve ter o atributo android: onClick preenchido com o nome do método que tratará os cliques.
  • b. O botão deve ter o atributo android: click preenchido com o nome do método que tratará os cliques.
  • c. O botão deve ter o atributo android: onClickListener() com o nome do método que tratará os cliques.
  • d. O botão deve ter o atributo android: clickable="false".
  • e. O botão deve ter o atributo android: clickable preenchido com o nome do método que tratará os cliques.
Resposta: a. ✅

📌 Explicação:

  • No XML de layout do Android, para que um botão responda a eventos de clique declarativamente, usa-se o atributo android:onClick, indicando o nome do método que será chamado na Activity para tratar o clique.

Pergunta 8

As seguintes instruções são responsáveis por abrir uma nova tela no aplicativo Android:

                Intent it = new Intent(Tela_origem.this, Tela_destino.class);
                
                startActivity(it);

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • Essas instruções criam uma Intent para abrir a Tela_destino a partir da Tela_origem e, em seguida, iniciam a nova Activity com startActivity(it).
