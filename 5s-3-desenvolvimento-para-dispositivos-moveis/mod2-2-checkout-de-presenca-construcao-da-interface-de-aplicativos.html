Materiais

Neste módulo, você aprendeu sobre os principais gerenciadores de layout, os componentes da interface gráfica e seus atributos.

Considere a captura de tela presente na Figura 2. Trata-se de um aplicativo de conversão de valores de uma unidade monetária de origem para outra de destino. O aplicativo foi desenvolvido em Java para computadores (desktop).

Conteúdo

Descrição da imagem

A imagem mostra a interface de um programa chamado "Conversor de Moedas". No topo, há opções para selecionar a "Moeda de entrada" e a "Moeda de saída", com o Dólar (US) e Reais (BR) selecionados, respectivamente. O valor a ser convertido é $250,60.

Abaixo, há botões para "Converter" ou "Limpar" os campos. O campo "Valor convertido ($):" está vazio, aguardando o resultado da conversão. No canto inferior direito, há uma nota sobre a cotação do dia.

Sua tarefa é elaborar uma interface gráfica para aplicativo móvel, equivalente à deste aplicativo de computador, no Android Studio.

Orientações para elaboração e entrega da atividade:

  1. Recrie essa interface para ambiente Android.
  2. Escolha o gerenciador de layout que achar mais conveniente.
  3. Selecione os componentes visuais correspondentes.
  4. Customize os atributos (largura, altura, tamanho do texto, cores) dos componentes.
  5. Considerando que smartphones podem ser utilizados tanto na horizontal quanto na vertical, você deve organizar os componentes de acordo com a orientação de tela escolhida.
  6. Não é preciso fazer nenhuma implementação em Java.
  7. Copie o conteúdo (código) do arquivo XML do layout elaborado por você.
  8. Submeta o conteúdo do seu arquivo layout na tarefa do AVA.
