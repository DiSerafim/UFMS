Pergunta 1

Para que propósito deve ser usado um componente TextView?

  • a. Para ver documentos de texto.
  • b. Para exibir um texto que o usuário não pode editar.
  • c. Para servir como caixa de entrada de texto.
  • d. Para exibir um botão que o usuário pode clicar.
  • e. Para permitir que o usuário do aplicativo selecione texto.
Resposta: b. ✅

📌 Explicação:

  • O TextView é um componente da interface do usuário no Android usado para exibir texto estático, ou seja, texto que o usuário não pode modificar diretamente. Ele é comumente usado para mostrar títulos, descrições, mensagens, rótulos, entre outros.

Pergunta 2

Este valor faz com que o componente se ajuste ao tamanho do seu conteúdo. Ou seja, o componente será grande o suficiente apenas para acomodar o conteúdo que contém, sem espaço extra. Se layout_width ou layout_height estiverem definidos assim, o componente será tão largo ou tão alto quanto necessário para envolver seu conteúdo:

  • a. fill_content.
  • b. match_parent.
  • c. match_content.
  • d. wrap_parent.
  • e. wrap_content.
Resposta: e. ✅

📌 Explicação:

  • No desenvolvimento Android, ao usar wrap_content em layout_width ou layout_height, você está dizendo ao sistema:
    • “Ajuste o tamanho do componente exatamente ao tamanho do conteúdo que ele contém.”
  • wrap_content → o componente será apenas tão grande quanto o necessário para mostrar seu conteúdo.
  • match_parent → o componente vai ocupar todo o espaço disponível no pai.

Pergunta 4

Os componentes Checkbox, Switch e ToggleButton são utilizados para situações de opções não exclusivas.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ❌

📌 Explicação:

  • Checkbox: usado geralmente para opções não exclusivas, onde o usuário pode marcar várias opções ao mesmo tempo (ex: "Aceito receber e-mails", "Aceito os termos").
  • Switch e ToggleButton: usados normalmente para ativar ou desativar uma única funcionalidade, representando opções individuais, mas não necessariamente múltiplas ao mesmo tempo.

Pergunta 5

Esses dois gerenciadores de layouts oferecem flexibilidade na criação de layouts complexos com posicionamento relativo, o que pode ser particularmente útil na criação de designs responsivos que precisam se adaptar a diferentes tamanhos de tela. Ambos permitem posicionar componentes em relação a outros ou ao layout pai. Pode-se também alinhar componentes nas laterais, na parte superior ou inferior de outros componentes ou do contêiner de layout.

  • a. Constraint Layout e Grid Layout.
  • b. Constraint Layout e Table Layout.
  • c. Constraint Layout e Linear Layout.
  • d. Constraint Layout e Relative Layout.
  • e. Constraint Layout e Frame Layout.
Resposta: d. ✅
  • RelativeLayout Permite posicionar elementos relativamente entre si e ao pai.
  • ConstraintLayout Mais moderno e flexível. Permite posicionamento relativo mais avançado, alinhamentos complexos, e melhor desempenho em alguns casos.

Pergunta 6

NÃO é um atributo útil do componente ImageView:

  • a. layout_width.
  • b. layout_height.
  • c. src.
  • d. scaleType.
  • e. Nenhuma das alternativas.
Resposta: e. ✅

📌 Explicação:

  • Todos os atributos listados são úteis e válidos para o componente ImageView no Android:
    • layout_width Define a largura da imagem no layout.
    • layout_height Define a altura da imagem no layout.
    • src Especifica a imagem que será exibida no ImageView.
    • scaleType Controla como a imagem será escalada/dimensionada dentro do ImageView.

Pergunta 8

As unidades recomendadas para dimensionar texto e componentes, respectivamente, no Android são:

  • a. sp e px.
  • b. pt e px.
  • c. px e pt.
  • d. sp e dp.
  • e. dp e sp.
Resposta: d. ✅

📌 Explicação:

  • sp (scale-independent pixels) → usada para tamanho de texto
    • Respeita as configurações de acessibilidade do usuário (ex: tamanho de fonte maior).
  • dp (density-independent pixels) → usada para tamanho de componentes (layouts, botões, margens etc.)
    • Garante que o layout fique consistente em diferentes densidades de tela.

Pergunta 9

Tipo de gerenciador de layout com divisões internas chamadas de Row:

  • a. Relative Layout.
  • b. Linear Layout.
  • c. Frame Layout.
  • d. Constraint Layout.
  • e. Table Layout.
Resposta: e. ✅

📌 Explicação:

  • O TableLayout é um gerenciador de layout no Android que organiza os componentes em linhas (Row) e colunas, semelhante a uma tabela HTML.
    • Cada linha é representada por um TableRow.
    • Dentro de cada TableRow, você pode colocar células (componentes como TextView, EditText, etc.).
    • Muito usado quando se quer um layout em formato de grade ou tabela.

Pergunta 10

O componente RadioButton é uma forma comum de permitir que os usuários façam uma única seleção em uma lista de opções.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

📌 Explicação:

  • O RadioButton é usado em Android (e outras interfaces gráficas) para permitir que o usuário selecione apenas uma opção entre várias.
    • Ele normalmente é usado dentro de um RadioGroup, que garante que somente uma opção seja selecionada por vez.
