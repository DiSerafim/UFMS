Materiais

Neste módulo, você aprendeu sobre programação de aplicativos, o tratamento de eventos do usuário e construção de aplicativos com mais de uma tela.

O tratamento de eventos permite que os desenvolvedores criem interfaces de usuário interativas e dinâmicas, onde a lógica de resposta é separada da sequência principal do programa, promovendo assim uma arquitetura de software mais limpa e modular.

Sua tarefa é implementar os eventos e a programação das funcionalidades do aplicativo de conversão de moedas, cuja interface gráfica foi criada no módulo anterior.

Conteúdo

Orientações para elaboração e entrega da atividade:

  1. Abra seu projeto de aplicativo conversor de moedas do módulo anterior.
  2. Implemente os métodos de clique dos botões “Converter” e “Limpar”.
  3. O botão “Converter” deverá realizar o cálculo de conversão do valor em dólares (US$) para reais (R$), ou de reais (R$) para dólares (US$), de acordo com a seleção do usuário, e exibir o resultado no componente adequado.
  4. Pode-se considerar a taxa de conversão: 1 dólar = 5 reais.
  5. O botão “Limpar” deverá remover o conteúdo dos campos de textos e desfazer a seleção nas caixas de seleção.
  6. Copie o código Java, da classe principal, desenvolvido.
  7. Submeta o conteúdo do código no espaço da tarefa no AVA.

            package com.example.conversordemoeda;

            import android.os.Bundle;
            import android.view.View;
            import android.widget.ArrayAdapter;
            import android.widget.Button;
            import android.widget.EditText;
            import android.widget.Spinner;
            import android.widget.TextView;
            
            import androidx.activity.EdgeToEdge;
            import androidx.appcompat.app.AppCompatActivity;
            import androidx.core.graphics.Insets;
            import androidx.core.view.ViewCompat;
            import androidx.core.view.WindowInsetsCompat;
            
            public class MainActivity extends AppCompatActivity {
            
                private Spinner spEntrada, spSaida;
                private EditText etValor;
                private TextView tvResultado;
                private Button btConverter, btLimpar;
            
                private final double TAXA_CONVERSAO = 5.0;
            
                @Override
                protected void onCreate(Bundle savedInstanceState) {
                    super.onCreate(savedInstanceState);
                    EdgeToEdge.enable(this);
                    setContentView(R.layout.activity_main);
                    ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
                        Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
                        v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
                        return insets;
                    });
            
                    spEntrada = findViewById(R.id.spEntrada);
                    spSaida = findViewById(R.id.spSaida);
                    etValor = findViewById(R.id.etValor);
                    tvResultado = findViewById(R.id.tvResultado);
                    btConverter = findViewById(R.id.btConverter);
                    btLimpar = findViewById(R.id.btLimpar);
            
                    // Prenche o spinner
                    String[] moedas = { "Dolar (US$)", "Real (R$)" };
                    ArrayAdapter adapter = new ArrayAdapter<>(this, android.R.layout.simple_spinner_item, moedas);
                    adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item);
                    spEntrada.setAdapter(adapter);
                    spSaida.setAdapter(adapter);
            
                    // Btn Converter
                    btConverter.setOnClickListener(new View.OnClickListener() {
                        @Override
                        public void onClick(View view) {
                            String moedaOrigem = spEntrada.getSelectedItem().toString();
                            String moedaSaida = spSaida.getSelectedItem().toString();
                            String valorStr = etValor.getText().toString();
            
                            if (!valorStr.isEmpty()) {
                                double valor = Double.parseDouble(valorStr);
                                double resultado;
            
                                if (moedaOrigem.equals("Dolar (US$)") && moedaSaida.equals("Real (R$)")) {
                                    resultado = valor * TAXA_CONVERSAO;
                                    tvResultado.setText(String.format("R$ %.2f", resultado));
                                } else if (moedaOrigem.equals("Real (R$)") && moedaSaida.equals("Dolar (US$)")) {
                                    resultado = valor / TAXA_CONVERSAO;
                                    tvResultado.setText(String.format("US$ %.2f", resultado));
                                } else {
                                    tvResultado.setText("Insita um valor válido!");
                                }
                            }
                        }
                    });
            
                    // Btn Limpar
                    btLimpar.setOnClickListener(new View.OnClickListener() {
                        @Override
                        public void onClick(View view) {
                            etValor.setText("");
                            tvResultado.setText("");
                            spEntrada.setSelection(0);
                            spSaida.setSelection(0);
                        }
                    });
                }
            }
