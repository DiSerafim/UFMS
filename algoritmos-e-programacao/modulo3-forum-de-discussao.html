Módulo 3 - 💬 Fórum de Discussão

💬 Entrada, saída de dados e modularização

"uma vez conhecendo determinada linguagem, aprender outras fica bem mais fácil".
Com isso em mente, te convido a discutir neste fórum as seguintes questões:

1- Quais são as principais diferenças entre o Python e a linguagem C no que diz respeito às variáveis, entrada e saída de dados e sintaxe?

- Python, não precisa declarar explicitamente o tipo de uma variável, e ela pode mudar de tipo durante a execução do programa.
- Python oferece funções de entrada e saída que facilitam a leitura e escrita de dados.
- Python utiliza a indentação para definir blocos de código.

- C as variáveis são do tipo explícitas e não permite mudanças de tipo.
- C, a entrada e saída é feita usando funções.
- C usa chaves {} para delimitar blocos de código.

2- Você acha as duas linguagens parecidas ou não? Explique o porquê.

Ambas as linguagens compartilham conceitos de programação, como estruturas condicionais e de repetição.
Python é considerada mais fácil de aprender.
C é mais eficiente em termos de recursos e de hardware.

Embora compartilhem alguns conceitos de programação, suas abordagens e sintaxe são diferentes.
