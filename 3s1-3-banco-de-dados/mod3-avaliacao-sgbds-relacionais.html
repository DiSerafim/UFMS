Pergunta 1

Índice de agrupamento foi criado para atributos não chave, possui uma entrada no arquivo de índice para cada valor distinto do campo de agrupamento, é esparso.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Resolução:

  • Um índice de agrupamento (clustered index) pode ser criado em atributos que não são chave primária. Ele possui uma entrada no arquivo de índice para cada valor distinto do campo de agrupamento e é esparso, pois não há uma entrada no índice para cada registro da tabela, mas sim para cada grupo de registros que compartilham o mesmo valor no campo de agrupamento..

Pergunta 2

No contexto de controle de concorrência, o deadlock (impasse) ocorre quando cada transação T em um conjunto de duas ou mais transações está esperando por algum item que está bloqueado por alguma outra transação T’ no conjunto.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Resolução:

  • No contexto de controle de concorrência, um deadlock (impasse) ocorre quando cada transação em um conjunto de duas ou mais transações está esperando por algum recurso (como um item de dados) que está bloqueado por outra transação no conjunto. Isso cria uma situação em que nenhuma das transações pode prosseguir, resultando em um impasse..

Pergunta 3

Em um banco de dados relacional, índices são usados para:

  • a. Permitir a localização eficiente de registros tabelas.
  • b. Possuir a lista dos usuários com permissões em uma tabela.
  • c. Identificar os registros válidos e os registros excluídos de uma tabela.
  • d. Apontar para a posição do último registro inserido na tabela.
  • e. Ordenar uma tabela por meio do identificador de registro.
Resposta: a. ✅

Resolução:

  • Índices em bancos de dados relacionais são estruturas que melhoram a velocidade das operações de busca. Eles permitem a localização rápida e eficiente de registros dentro de uma tabela, baseando-se nos valores de uma ou mais colunas indexadas.

Pergunta 4

Assinale todas as alternativas que possuem schedules que são serializáveis (de conflito)?

Considere:

  • r a operação de leitura read_item.
  • w a operação de escrita write_item.

Obs.: Cada alternativa errada que for marcada anula a pontuação que seria recebida por uma alternativa correta.

  • a. r1 (Y); r3 (X); w1 (Y); r2 (X); w3 (Y);
    •                         T1  T2
                        🡻
                        T3
  • b. r1 (X); r3 (X); w3 (X); w1 (X); r2 (X);
    •                         T1  T2
                        🡻🡹
                        T3
  • c. r3 (X); r2 (X); w3 (X); r1 (X); w1 (X);
    •                         T1  🢀T2
                        🡹   🡿
                        T3
  • d. r3 (X); r2 (X); r1 (X); w3 (X); w1 (X);
    •                         T1  🢀T2
                        🡻🡹   🡿
                        T3
  • e. Nenhum dos schedules apresentados são seriálizáveis por conflito.
Resposta: a.✅ c.✅ d.❌

Resolução:

  • Os schedules serializáveis são aqueles em que as transações ocorrem de forma que o resultado seja equivalente a alguma serialização das transações, ou seja, o resultado final é o mesmo que se as transações tivessem sido executadas sequencialmente, uma após a outra. Nas alternativas corretas (a, c, d), as operações de leitura e escrita não causam conflitos diretos entre as transações, o que permite que elas possam ser serializadas de forma eficiente, mantendo a consistência dos dados.

Pergunta 5

Em um banco de dados, uma transação é uma unidade lógica que começa com a operação BEGIN TRANSACTION e, se o término for bem sucedido, há uma operação específica que informa ao gerenciador de transações que uma unidade lógica de trabalho foi concluída. Essa operação é denominada:

  • a. RECOVER.
  • b. COMMIT.
  • c. SUCCESS.
  • d. ABORT.
  • e. ROLLBACK.
Resposta: b. COMMIT. ✅

Resolução:

  • Quando uma transação é concluída com sucesso em um banco de dados, ou seja, todas as suas operações foram executadas corretamente e os resultados estão prontos para serem permanentemente salvos no banco de dados, utiliza-se a operação COMMIT. Essa operação sinaliza ao sistema de gerenciamento de banco de dados que todas as mudanças feitas pela transação devem ser confirmadas e tornadas permanentes. Após o COMMIT, os dados modificados pela transação se tornam visíveis para outros usuários e transações.

Pergunta 6

No contexto de processamento de transações, se uma transação está calculando uma função de resumo de agregação em uma série de itens de banco de dados, enquanto outras transações estão atualizando alguns desses itens, a função de agregação pode calcular alguns valores antes que eles sejam atualizados e outros, depois que eles forem atualizados. Esse problema é denominado:

  • a. Atualização temporária.
  • b. Leitura suja.
  • c. Leitura na repetitiva.
  • d. Atualização perdida.
  • e. Resumo incorreto.
Resposta: b. Leitura suja. ❌

Pergunta 7

Em um banco de dados, uma transação é uma unidade lógica que começa com a operação BEGIN TRANSACTION e, se o término da execução dessa transação NÃO for bem-sucedido, há uma operação específica que informa ao gerenciador de transações que algo deu errado e, a partir desse ponto, tudo que foi realizado até o momento precisará ser desfeito. Essa operação é denominada:

  • a. COMMIT.
  • b. RECOVER.
  • c. ABORT.
  • d. ROLLBACK.
  • e. SUCCESS.
Resposta: d. ROLLBACK. ✅

Resolução:

  • O comando ROLLBACK é usado para reverter ou desfazer uma transação que não foi concluída com sucesso, restaurando o banco de dados para o estado anterior à transação. Isso garante a consistência dos dados e evita mudanças indesejadas no banco de dados devido a uma transação mal-sucedida.

Pergunta 8

Índice primário é baseado na chave primária, é do tipo denso e seu número de entradas no índice é igual ao número de blocos de disco no arquivo de dados.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Falso. ✅

Resolução:

  • Um índice primário é baseado na chave primária e é, de fato, denso, mas o número de entradas no índice não é necessariamente igual ao número de blocos de disco no arquivo de dados. Em muitos casos, o número de entradas no índice pode ser menor do que o número de blocos de disco, especialmente se o índice for particionado ou se o fator de preenchimento não for 100%.

Pergunta 10

Um índice é uma estrutura auxiliar associado a uma tabela.

Escolha uma opção: Verdadeiro ou Falso.

Resposta: Verdadeiro. ✅

Resolução:

  • Um índice em um banco de dados é de fato uma estrutura auxiliar associada a uma tabela. Ele é usado para melhorar a eficiência das consultas, permitindo que o sistema de gerenciamento de banco de dados (SGBD) localize rapidamente as linhas de uma tabela que correspondem a determinados critérios de pesquisa. Em vez de percorrer todas as linhas da tabela, o SGBD pode usar o índice para localizar diretamente as linhas relevantes. Isso resulta em consultas mais rápidas e eficientes.
