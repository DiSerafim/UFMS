Materiais

A linguagem SQL (Structured Query Language) permite que o projetista de banco de dados defina sua estrutura, além de possibilitar que usuários/aplicações realizem operações de CRUD (create, read, update e delete) em informações gravadas no banco de dados.

Conteúdo

Cite um comando SQL que execute uma das operações de CRUD na tabela DEPARTAMENTO abaixo. Explique o que o seu comando SQL realizou no banco de dados e qual é o resultado esperado.

DEPARTAMENTO
id nome cpf_gerente
1 Pesquisa 333445555
2 Administração 987654321
3 Engenharia 888665555
4 Inovação NULL
5 Computação NULL

Exemplo: INSERT INTO departamento (id,nome) VALUES (6,'Sistemas');

Esse comando serve para inserir uma nova tupla na tabela departamento. Essa tupla representa o departamento de nome ‘Sistemas’ que possui como chave primária o id com o valor 6 e não possui um gerente.

CRUD (Update)

                UPDATE departamento
                SET nome = 'T.I.'
                WHERE id = 5;

O comando UPDATE modifica a tabela 'departamento', na coluna 'nome' onde o 'id' é 5, atualizando para 'T.I.'.
