Materiais

A linguagem SQL pode ser considerada um dos principais motivos para o sucesso dos SGBDs relacionais. Parte desse sucesso se deu porque a linguagem se tornou um padrão para esse tipo de banco de dados. Dessa forma, se o usuário estivesse insatisfeito com com o SGBD adotado, a migração para outro SGBD relacional não seria tão complexa uma vez que os dois SGBDs atuam sobre o mesmo padrão.

Modelo Relacional.

Sob essa perspectiva, considere o modelo relacional abaixo, para realizar a seguinte consulta: para cada departamento, que possui mais de 2 funcionários, a consulta deve retornar o nome do departamento, o número de funcionários que trabalham em cada departamento e a média salarial dos funcionários.

  • FUNCIONARIO (cpf, nome, datanasc, salario, dnumero (FK departamento.dnumero))
  • DEPARTAMENTO (dnumero, nome, cpf_gerente (FK funcionario.cpf))
  • PROJETO (projnumero, projnome, dnumero (FK departamento.dnumero))
  • TRABALH_EM (cpf (FK funcionario.cpf), projnumero (FK projeto.prjnumero), horas)

Utilize boas práticas de banco de dados para realizar as junções considerando todas as restrições estabelecidas no modelo relacional.

                SELECT D.nome AS nome_departamento
                    COUNT(F.cpf) AS numero_funcionarios
                    AVG(F.salario) AS media_salarial
                FROM DEPARTAMENTO D
                JOIN FUNCIONARIO F ON D.dnumero = F.dnumero
                GROUP BY D.nome
                HAVING COUNT(F.cpf) > 2;
  • O SELECT seleciona o nome do departamento 'D.nome AS nome_departamento'
  • 'COUNT(F.cpf) AS numero_funcionarios', conta o número de funcionários no departamento.
  • 'AVG(F.salario) AS media_salarial', calculka a média salarial dos funcionários nos departamentos.
  • 'FROM DEPARTAMENTO D', indica que a tabela departamento usará o alias D.
  • 'JOIN FUNCIONARIO F ON D.dnumero = F.dnumero', faz uma junção entre as tabelas D e F onde os valores 'dnumero' coincidem.
  • 'GROUP BY D.nome', agrupa os resultados pelo nome do departamento.
  • 'HAVING COUNT(F.cpf) > 2;', filtra os grupos para incluir apenas os que tem mais que dois funcionários.
