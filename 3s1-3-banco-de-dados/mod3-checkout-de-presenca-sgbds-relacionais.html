Materiais

Segundo Navathe, o conceito de transação oferece um mecanismo para descrever unidades lógicas de processamento de banco de dados. Os sistemas de processamento de transação são sistemas com grandes bancos de dados e centenas de usuários simultâneos que executam transações de banco de dados. Alguns exemplos desses sistemas incluem reservas aéreas, sistemas bancários, processamento de cartão de crédito, compras on-line, mercados de ações, caixas de supermercado e muitas outras aplicações. Esses sistemas exigem alta disponibilidade e tempo de resposta rápido para centenas de usuários simultâneos.

Conteúdo

Transação íntegra - ACID.

Uma transação, para ser considerada íntegra, deve possuir quatro propriedades conhecidas pelo acrônimo ACID.

Escreva de forma detalhada cada uma dessas propriedades e seu significado.

Atomicidade, Consistência, Isolamento e Durabilidade.

  • Essas propriedades são essenciais para garantir que as transações sejam executadas corretamente e que o banco de dados mantenhas um estado consistente.
Atomicidade:
  • Garante que todas as operações de uma transação seja completamente executada ou não seja executada de forma alguma.
    • Se uma transação é iniciada e não puder ser concluída, o sistema de banco de dados deve garantir que todas as operações realizadas até aquele ponto sejam desfeitas, retornando ao banco de dados ao seu estado de inicio da transação.
Consistência:
  • Garante que uma transação leve o banco de dados de um estado válido a outro estado válido, mantendo a integridade dos dados conforme regras definidas.
    • Antes e depois das transações todas as regras de integridade devem ser respeitadas. Todas as regras de negócios, validações e constraints devem ser aplicadas.
Isolamento:
  • Garante que as operações de uma transação sejam isoladas das operações de outras ações simultâneas.
    • Previne problemas com leituras sujas (dirty read), leitura não repetível (non-repeatable read) e fantasma (phantom reads). Níveis de isolamento (Read Uncommitted, Read Committed, Repeatable Read e Serializable).
Durabilidade:
  • Garante que uma vez que uma transação foi confirmada (commited), seus efeitos são permanentes e persistirão.
    • Os dados modificados por uma transação bem-sucedida são gravados permanentemente no armazenamento. Isso geralmente é implementado através do uso de logs de transação e técnicas de recuperação de desastres.
