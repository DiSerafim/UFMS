    A cláusula LEFT JOIN em SQL retorna todas as linhas e colunas da tabela da esquerda, mesmo que não haja correspondência na tabela da direita.

    Escolha uma opção: Verdadeiro ou Falso.

    Resposta: Verdadeiro. ✅

    Resolução:

  • A cláusula LEFT JOIN em SQL retorna todas as linhas da tabela da esquerda (a primeira tabela mencionada na cláusula), junto com os dados correspondentes da tabela da direita (a segunda tabela mencionada).                     DEPARTAMENTO

                ID      NOME                    STATUS
                1       Administração           Ativo
                2       Inovação                Ativo
                3       Ciência e Tecnologia    Inativo
                4       Robótica                Ativo
                5       Informação              Pendente

    A partir da tabela DEPARTAMENTO, assinale a alternativa que apresente um comando SQL que irá retornar a quantidade de departamentos que não estão ativos.

    • a. SELECT COUNT(*) FROM DEPARTAMENTO WHERE STATUS <> 'Ativo';
    • b. SELECT DISTINCT FROM DEPARTAMENTO WHERE STATUS = 'Inativo' OR STATUS='Pendente';
    • c. SELECT ID FROM DEPARTAMENTO WHERE STATUS NOT IN ('Ativo');
    • d. SELECT COUNT(*), STATUS FROM DEPARTAMENTO GROUP BY STATUS;
    • e. SELECT SUM(ID) FROM DEPARTAMENTO WHERE STATUS IN ('Inativo','Pendente');

    Resolução:

  • Este comando conta todas as linhas na tabela DEPARTAMENTO onde o valor da coluna STATUS não é 'Ativo'. Esta é a forma correta de contar os departamentos que têm um status diferente de 'Ativo'.
  • O símbolo <> em SQL é um operador de comparação que significa "diferente de". Ele é usado em condições WHERE para filtrar resultados que não atendem a uma determinada condição.

    A cláusula LEFT JOIN em SQL retorna todas as linhas da tabela da esquerda, desde que haja uma correspondência na tabela da direita. Porém, só retorna as colunas que possuam valores em comum.

    Escolha uma opção: Verdadeiro ou Falso.

    Resposta: Falso. ✅

    Resolução:

    Pergunta 8

    É utilizado para combinar o resultado de dois ou mais comandos SELECT. Cada comando SELECT deve conter o mesmo número de colunas, as colunas devem contar tipos similares de dados e devem estar na mesma ordem em cada comando SELECT. O operador SQL, em questão, é chamado:

    • a. INTO.
    • b. UNION.
    • c. ORDER BY.
    • d. WHERE.
    • e. LEFT JOIN.
    Resposta: b. UNION. ✅

    Resolução:

  • O operador UNION em SQL é utilizado para combinar o resultado de dois ou mais comandos SELECT. Cada comando SELECT deve conter o mesmo número de colunas, as colunas devem ter tipos similares de dados e devem estar na mesma ordem em cada comando SELECT. O UNION elimina as duplicatas por padrão, enquanto o UNION ALL inclui todas as duplicatas.

    • Pergunta 9

    A cláusula having está associada à cláusula group by.

    Escolha uma opção: Verdadeiro ou Falso.

    Resposta: Verdadeiro. ✅

    Resolução:

    • A cláusula HAVING em SQL é usada em conjunto com a cláusula GROUP BY para filtrar os resultados agregados. Enquanto a cláusula WHERE filtra linhas antes de qualquer agrupamento, a cláusula HAVING filtra grupos depois que o agrupamento é realizado. Portanto, HAVING é sempre usado com GROUP BY.

    Pergunta 10

    Letícia é analista de sistemas e precisa remover todos os registros da tabela “pedido” que possuam o “preco” menor ou igual 100. Assinale a alternativa correta que permita a Letícia executar sua tarefa:

    • a. EXCLUIR FROM pedido WHERE preco <= 100;
    • b. DELETE FROM pedido WHERE preco<=100;< /li>
    • c. TRUNCATE FROM pedido WHERE LIKE preco<=100;< /li>
    • d. DELETE * FROM pedido WHERE preco IS LESS THAN 100;
    • e. DROP pedido WHERE preco <= 100;
    Resposta: b. ✅

    Resolução:

    • A cláusula DELETE FROM é utilizada para remover registros de uma tabela.
    • Em seguida, é especificada a tabela da qual se deseja deletar registros, que no caso é "pedido".
    • A condição WHERE preco <= 100 indica que apenas os registros em que o valor da coluna "preco" seja menor ou igual a 100 serão removidos.
